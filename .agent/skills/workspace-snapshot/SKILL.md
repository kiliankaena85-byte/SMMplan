# 🔗 Workspace Snapshot — Резервное копирование изменений

Скилл `workspace-snapshot` обеспечивает создание мгновенного локального резервного снимка (бэкапа) файлов проекта и ключевых переменных среды перед проведением масштабного рефакторинга кода или обновлением зависимостей. Это дает гарантию безопасного отката (rollback) в случае ошибок.

## When to activate

| Ситуация / Триггер | Описание | Действие |
| :--- | :--- | :--- |
| **Крупный рефакторинг** | Перед изменением структуры файлов или редактированием ключевых компонентов | Создать снимок перед началом работы |
| **Обновление зависимостей** | Перед запуском `npm update` или установкой новых библиотек | Создать снимок во избежание конфликтов |
| **Смена этапа разработки** | При переходе к новому milestone или перед передачей задачи | Сохранить стабильную версию |

## Scope boundaries

### В рамках скилла
- Создание сжатых zip/tar архивов рабочей директории в `.backups/`.
- Исключение служебных папок (`node_modules`, `.next`, `.git`, `.backups`) для оптимизации размера архива.
- Резервное копирование локальной конфигурации окружения (`.env` файлы).

### Вне рамок скилла
- Загрузка резервных копий на внешние серверы или в облачные хранилища.
- Полное управление версиями Git (это задача для Git CLI).
- Автоматический откат без подтверждения от пользователя.

## Step-by-step execution protocol

1. **Предварительный аудит**: Убедитесь, что все важные несохраненные изменения находятся в текущем каталоге.
2. **Запуск скрипта**: Выполните команду запуска резервного копирования:
   ```bash
   npx tsx .agent/skills/workspace-snapshot/scripts/snapshot.ts
   ```
3. **Проверка логов**: Дождитесь завершения работы скрипта. Вы должны увидеть сообщение об успешном создании бэкапа и путь к `.zip` архиву в `.backups/`.
4. **Валидация архива**: При необходимости убедитесь, что архив физически создан в папке `.backups/` и имеет ненулевой размер.

## Error handling

- **Недостаточно свободного места на диске**: Скрипт прерывает выполнение с кодом `1` и сообщает об ошибке. Освободите место и повторите запуск.
- **Ошибка прав доступа**: Если файл заблокирован другой программой, освободите файл или запустите терминал с повышенными правами.
- **Гигантский размер архива**: Если архивирование занимает слишком много времени, проверьте `.gitignore` и исключите тяжелые каталоги.
