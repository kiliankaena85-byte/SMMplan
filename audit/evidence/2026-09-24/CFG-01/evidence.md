# Доказательства ремедиации CFG-01 (Изоляция приватных LAN подсетей в allowedOrigins)

## До исправления (Before)
В `next.config.mjs:45-51` конфигурация `allowedOrigins` для Server Actions содержала подстановочные маски локальных и приватных подсетей (`192.168.*`, `10.*`, `26.*`), которые безусловно попадали в результирующий список даже в боевом контуре (`isProdContour`):
```javascript
const localOrigins = [
  'localhost',
  'localhost:3000',
  '127.0.0.1',
  '192.168.*',
  '192.168.*:3000',
  '10.*',
  '10.*:3000',
  '26.*',
  '26.*:3000',
];
```
В боевой среде это создавало риски CSRF и подделки заголовка Origin из корпоративных VPN и частных подсетей.

## После исправления (After)
1. В `next.config.mjs` включение подсетей `192.168.*`, `10.*`, `26.*` изолировано условием `isProdContour`:
   ```javascript
   const localOrigins = isProdContour ? [
     'localhost:3000',
     '127.0.0.1:3000',
   ] : [
     'localhost',
     'localhost:3000',
     'localhost:3001',
     '127.0.0.1',
     '127.0.0.1:3000',
     '127.0.0.1:3001',
     '0.0.0.0:3000',
     'host.docker.internal:3000',
     '192.168.*',
     '192.168.*:3000',
     '10.*',
     '10.*:3000',
     '26.*',
     '26.*:3000',
   ];
   ```
2. В боевом режиме (`isProdContour === true`) внешние подстановочные маски приватных сетей исключены.

- `npx tsc --noEmit` — 0 ошибок (PASS).
