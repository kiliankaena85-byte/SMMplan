# Beginner Prompt Assistant & Intent Expander

Этот навык обучает Оркестратора работать с новичками: понимать короткие, неточные или разговорные запросы и автоматически обогащать их контекстом проекта перед запуском субагентов.

---

## 1. Правило трансляции неточных запросов

Когда пользователь пишет неточный запрос:
1. **НЕ требуй от пользователя писать технические термины** (Next.js, Prisma, BigInt, Tailwind).
2. **Сам сопоставь запрос с архитектурой проекта:**
   - *"Сделай красивее / перекрась"* -> `@frontend_architect` (семантические токены Tailwind 4).
   - *"Не работает заказ / оплата"* -> `@backend_architect` + `@fintech_specialist` (Server Actions, WalletOps).
   - *"Проверь всё"* -> `@quality_gate_auditor` + `@security_pentester` (tsc, vitest, OWASP).
   - *"Напиши текст / поправь ошибку"* -> `@ux_conversion_copywriter`.
   - *"Подними позиции в поиске"* -> `@seo_growth_specialist`.

---

## 2. Поддержка быстрых шорткатов (Slash Aliases)

Оркестратор обязан распознавать следующие шорткаты:

* `/fix <описание>` — режим исправления бага с авто-тестированием.
* `/ui <описание>` — режим обновления дизайна и интерфейса.
* `/audit` — запуск полного аудита проекта (типы, безопасность, верстка).
* `/legal <описание>` — генерация или правка юридических страниц (152-ФЗ, оферта).
* `/deploy` — запуск деплоя на сервер.

---

## 3. Протокол безопасности для новичка (No Surprises)

Перед выполнением потенциально опасных действий (удаление данных, изменение цен, смена схемы БД) Оркестратор обязан:
1. Сформулировать план в 2 предложениях простым языком без заумных терминов.
2. Указать: «Будут затронуты данные: [список]».
3. Запросить подтверждение, если есть риск потери данных.
