# 👑 Руководство Администратора: Настройка доступа и RBAC (Admin Setup)

В **SMMplan / SMMflux** реализована строгая ролевая модель доступа (**RBAC — Role-Based Access Control**), разграничение привилегий для персонала и защита от несанкционированного доступа.

---

## 🚀 1. Первичное создание Супер-Администратора

После первого развертывания проекта создайте владельца системы с полным доступом (`OWNER`):

### Вариант А: Интерактивный терминальный мастер
```bash
npx tsx scripts/setup-first-admin.ts
```
Скрипт запросит:
1. Email администратора (например, `owner@smmplan.pro`)
2. Надежный пароль (мин. 8 знаков)
3. Роль (по умолчанию `OWNER`)
4. Тенанты (создается одновременно для `smmplan` и `flux`)
5. Стартовый тестовый баланс

### Вариант Б: Быстрая однострочная команда
```bash
npx tsx scripts/setup-first-admin.ts --email admin@smmplan.pro --password SecretPassword2026! --role OWNER --balance 100000
```

---

## 🛡️ 2. Иерархия ролей (RBAC)

В системе определены 5 уровней доступа:

| Роль | Права доступа | Назначение |
| :--- | :--- | :--- |
| **`OWNER`** | 100% полный доступ. Финансы, управление провайдерами, выдача ролей, настройки 54-ФЗ, удаление данных. | Владелец бизнеса / Главный архитектор |
| **`ADMIN`** | Управление каталогом, заказами, пользователями, модерация тикетов. Заблокирован доступ к смене владельца. | Старший администратор |
| **`FINANCE`** | Просмотр финансового гроссбуха, сверка балансов, аудит платежей ЮKassa/Robokassa, управление комиссиями. | Бухгалтер / Финансовый контролер |
| **`SUPPORT`** | Доступ к тикетам поддержки, просмотр заказов, ручной рефилл/перезапуск зависших задач. | Оператор службы поддержки |
| **`MARKETER`** | Редактирование текстов, SEO-метатегов, промо-акций, баннеров и статей блога. | Маркетолог / Контент-менеджер |

---

## 🔑 3. Вход в панель управления

1. Откройте страницу авторизации: **`http://localhost:3000/login`**
2. Введите Email и пароль созданного администратора.
3. После успешного входа перейдите в панель управления:
   * **URL админки:** **`http://localhost:3000/admin`**
   * *Для сотрудников с ограниченными ролями доступ автоматически фильтруется через `requireStaffPermission()`.*

---

## 🔄 4. Сброс пароля и Magic Link для входа

### Смена пароля администратора через консоль:
Если вы забыли пароль:
```bash
npx tsx scripts/set-admin-password.ts --email admin@smmplan.pro --password NewStrongPassword2026!
```

### Генерация прямой одноразовой ссылки для входа (Magic Link):
Для быстрого входа без ввода пароля:
```bash
npx tsx scripts/gen-magic.ts --email admin@smmplan.pro
```
Скрипт сгенерирует готовую подписанную ссылку:
```text
🔗 Ссылка для входа: http://localhost:3000/auth/verify?token=eyJh...
```

## 🏢 5. Управление Мульти-Тенантностью

Один и тот же администратор может иметь учетную запись как на **SMMplan**, так и на **SMMflux**.
* В базе данных PostgreSQL пользователи изолированы уникальным составным ключом `@@unique([email, tenantId])`.
* Балансы, заказы и тикеты между тенантами **строго изолированы**.
* Супер-администратор в панели `/admin` видит глобальную аналитику и может переключать контекст тенантов в шапке.

---

## 🔒 6. Финансовая безопасность и Trust Boundary

* ❌ **Запрещено менять баланс напрямую в БД:** Прямой SQL-запрос `UPDATE "User" SET balance = ...` нарушит целостность гроссбуха `FinancialLedger`.
* ✅ Все начисления и списания осуществляются строго через админ-панель (раздел «Пользователи» ➔ «Корректировка баланса») с обязательной фиксацией причины в аудит-логе.
