# audit/tools — инструменты аудита (не для сборки!)

Эти файлы созданы в ходе аудита в окружении, где недоступны движки Prisma
(`binaries.prisma.sh` заблокирован), и **не участвуют** в сборке, CI или рантайме проекта.

| Файл | Назначение | Как использовать |
|---|---|---|
| `prisma-type-stub.py` | Генерирует `node_modules/.prisma/client/*.d.ts` из `prisma/schema.prisma`: типы моделей (точные — из схемы), аргументы запросов (`any`). Нужен, чтобы `tsc` не тонул в каскадных ошибках без сгенерированного клиента | `python3 audit/tools/prisma-type-stub.py prisma/schema.prisma node_modules/.prisma/client` |
| `prisma-runtime-stub.js` | Минимальный `PrismaClient` (прокси-делегаты), чтобы модули импортировались без движков. Для запуска тестов **непригоден** — вернёт пустые данные | `cp audit/tools/prisma-runtime-stub.js node_modules/.prisma/client/index.js` |

⚠️ **Правило:** результаты типового прогона со стабом нельзя использовать как доказательство дефектов —
только как способ сузить места для ручной проверки. Источник истины — `npx tsc --noEmit` с реальным
сгенерированным клиентом (как в CI) и прогоны на stage.
