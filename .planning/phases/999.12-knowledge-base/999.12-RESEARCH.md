## 4. Deep Findings & Technical Architecture

### 4.1. Архитектурный выбор: MDX vs. DB Collections (Q1)
Для Smmplan рекомендуется **гибридный подход с приоритетом Database-First**:
* **Почему не чистый MDX:** Чистый файловый MDX требует коммитов и деплоя для исправления каждой опечатки в статье. Для саппортов/копирайтеров это создаст барьер.
* **Решение:** Динамические статьи в PostgreSQL с полем Markdown/MDX в БД. Это позволит:
  * Редактировать статьи прямо из админ-панели Smmplan.
  * Реализовать статус публикации (`status: DRAFT / PUBLISHED`).
  * Связывать статьи с нашими локальными услугами из таблицы `Service` (например, под статьей про накрутку Telegram выводить виджет со ссылкой на покупку конкретных Telegram-подписчиков).

#### Предлагаемая Prisma модель (`schema.prisma`):
```prisma
model Article {
  id          String        @id @default(cuid())
  slug        String        @unique // URL-friendly название, например, "how-telegram-detects-bots"
  title       String        // Заголовок H1
  description String        // Meta description для SEO
  content     String        // Markdown-содержимое статьи
  status      ArticleStatus @default(DRAFT)
  category    String        @default("GENERAL") // "TELEGRAM", "INSTAGRAM", "MARKETING"
  viewCount   Int           @default(0)
  createdAt   DateTime      = now()
  updatedAt   DateTime      @updatedAt

  @@index([category])
  @@index([status])
}

enum ArticleStatus {
  DRAFT
  PUBLISHED
}
```

### 4.2. SEO & AEO Пакет Оптимизации (Q2)
Чтобы Yandex и Google считывали наш блог как первоисточник экспертного мнения, мы должны внедрить микроразметку `BlogPosting` через JSON-LD.

#### Next.js 16 Шаблон рендеринга JSON-LD (`app/knowledge/[slug]/page.tsx`):
```tsx
import { db } from '@/lib/db';
import { notFound } from 'next/navigation';

export async function generateMetadata({ params }: { params: { slug: string } }) {
  const article = await db.article.findUnique({ where: { slug: params.slug } });
  if (!article) return {};
  
  return {
    title: `${article.title} | База знаний Smmplan`,
    description: article.description,
    openGraph: {
      title: article.title,
      description: article.description,
      type: 'article',
      url: `https://smmplan.pro/knowledge/${article.slug}`,
      publishedTime: article.createdAt.toISOString(),
    }
  };
}

export default async function ArticlePage({ params }: { params: { slug: string } }) {
  const article = await db.article.findUnique({ where: { slug: params.slug } });
  if (!article || article.status !== 'PUBLISHED') notFound();

  const jsonLd = {
    '@context': 'https://schema.org',
    '@type': 'BlogPosting',
    headline: article.title,
    description: article.description,
    datePublished: article.createdAt.toISOString(),
    dateModified: article.updatedAt.toISOString(),
    author: {
      '@type': 'Organization',
      name: 'Команда Smmplan',
      url: 'https://smmplan.pro'
    },
    publisher: {
      '@type': 'Organization',
      name: 'Smmplan',
      logo: {
        '@type': 'ImageObject',
        url: 'https://smmplan.pro/logo.png'
      }
    }
  };

  return (
    <article className="max-w-3xl mx-auto px-4 py-8">
      {/* Безопасное внедрение JSON-LD */}
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c')
        }}
      />
      <h1 className="text-4xl font-extrabold mb-6 text-foreground">{article.title}</h1>
      <div className="prose dark:prose-invert max-w-none">
        {/* Отрендерить markdown-контент через безопасный парсер (например, ReactMarkdown) */}
      </div>
    </article>
  );
}
```

### 4.3. Технические инсайты для тем статей: Как соцсети выявляют накрутку в 2026 году (Q3)
Статьи должны давать жесткую техническую выжимку (это привлекает профессионалов):
1. **Fingerprinting & Цифровой отпечаток:** Рассказать о том, как алгоритмы Instagram/Telegram собирают отпечатки браузеров (Canvas, WebGL, аудио-контекст, установленные шрифты) и связывают ботов в сетки.
2. **Семантика прокси (IP Reputation):** Объяснить разницу между дешевыми серверными IPv4 прокси и мобильными/резидентными прокси. Почему дешевая накрутка списывается через 2 часа (высокий скоринг риска IP-подсети).
3. **Поведенческий ИИ (Behavioral AI):** Соцсети отслеживают координаты кликов, скорость движения курсора, время задержки (JS-события `mousemove`, `touchstart`) и частоту запросов.
4. **Удержание и качество вовлеченности (Retention Ratio):** Поисковые алгоритмы соцсетей пессимизируют каналы, у которых растет число подписчиков, но падает глубина просмотра постов. Накрутка "голых" цифр без активности — это яд для охватов.

### 4.5. Воронка нативной конверсии: Как продвигать Smmplan (Q5)
Чтобы статьи продавали наши услуги нативно и ненавязчиво, мы внедрим паттерн **«Конструктивный Рецепт»**:
1. **Проблема:** Статья детально и честно описывает проблему (например: дешевые боты вызывают списания и гробят охваты канала).
2. **Анализ:** Мы честно объясняем технические причины (соцсеть отслеживает плохие прокси и отсутствие активности ботов).
3. **Решение (Наш Оффер):** Мы даем читателю выбор:
   * *Вариант А (Дорогой/Сложный):* Настраивать свои мобильные прокси, покупать дорогие аккаунты и писать скрипты.
   * *Вариант Б (Быстрый/Надежный — Наше преимущество):* Использовать наши тарифы класса **«Premium / Активные пользователи»** в Smmplan. Мы пишем: *«В Smmplan мы отфильтровали 98% ненадежных поставщиков и используем только cherry-picked базы с мобильными резидентными IP. Наши умные алгоритмы распределяют накрутку порциями (Drip-feed), имитируя органический рост»*.
4. **Контекстные виджеты:** Под каждым разделом статьи выводить аккуратные плашки с актуальной ценой за 1 шт (semantic token `pricePerUnitRub` из нашей базы данных) для соответствующих услуг:
   * *Пример:* «Для безопасного старта рекомендуем: **Telegram Подписчики (Premium, Гарантия 30 дней)** — всего **0.24 ₽ / шт**».

## 5. Decision Log

1. **[DECISION] Use DB storage over static MDX:** MDX усложняет работу контент-менеджеров. Динамическая таблица `Article` в Prisma позволяет делать бесшовное редактирование, интеграцию виджетов услуг и быстрое переключение DRAFT/PUBLISHED.
2. **[DECISION] Render JSON-LD on Server Side:** Использование серверных компонентов Next.js для генерации структурированных данных Schema.org гарантирует, что поисковые роботы (включая Yandex Spider, не всегда полноценно выполняющий JS) корректно прочтут метаданные.
3. **[DECISION] Drip-feed & Quality Marketing Focus:** Позиционировать Smmplan в блоге не как «сервис дешевой автонакрутки», а как **«профессиональный инструмент органического ускорения и социального доказательства»**, ориентированный на качество аккаунтов и безопасность для клиентов.
