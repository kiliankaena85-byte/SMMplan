# Visual Localization — культурная адаптация визуалов

## When to activate

- Локализация изображений и иконок для конкретных рынков
- Проверка иконок на культурную нейтральность
- Адаптация цветов для разных культур
- Выбор изображений для мульти-рыночного продукта
- Пользователь упоминает cultural icons, visual localization, cultural adaptation

## Изображения — что адаптировать

### Люди на изображениях
- Разнообразие: разные этнические группы
- Для конкретного рынка: локальная аудитория
- Одежда: соответствует местным нормам (Ближний Восток: скромная одежда)
- Жесты: проверить культурную нейтральность (thumbs up = оскорбление в некоторых культурах)

### Еда
- Свинина: неприемлема в мусульманских и еврейских рынках
- Говядина: чувствительна в индийском рынке
- Решение: нейтральные продукты или овощи

### Цвета на изображениях
- Белый фон: траур в некоторых азиатских культурах
- Решение: нейтральные фоны + светлые тона

## Иконки — критические проблемы

### СТОП-лист иконок с культурными значениями

| Иконка | Проблема | Рынки |
|--------|----------|-------|
| Свинья/поросёнок | Религиозно чувствительна | Muslim, Jewish |
| Корова | Священное животное | Индия |
| Рука с пальцами (thumbs up) | Оскорбительный жест | Некоторые культуры MENA |
| Сова | Плохое предзнаменование | Некоторые африканские/азиатские |
| Число 4 | Несчастливое | Япония, Китай, Корея |
| Число 13 | Несчастливое | Западные культуры |

### БЕЗОПАСНЫЕ универсальные иконки
- Геометрические формы
- Технические объекты (компьютер, телефон, облако)
- Природные элементы (солнце, звезда, дерево)
- Общие UI паттерны (поиск, корзина, меню)

### Directional иконки — RTL проблема

```typescript
// Зеркалировать в RTL:
const MIRRORABLE_ICONS = [
  'arrow-left', 'arrow-right', 'chevron-left', 'chevron-right',
  'forward', 'reply', 'undo', 'redo', 'text-align-left'
]

// НЕ зеркалировать:
const NO_MIRROR_ICONS = [
  'search', 'heart', 'star', 'trash', 'settings',
  'user', 'home', 'clock', 'calendar', 'checkmark', 'close'
]
```

```css
[dir="rtl"] .icon--mirrored { transform: scaleX(-1); }
```

## Cultural Color Semantics

| Цвет | Запад | Китай | Индия | Ближний Восток |
|------|-------|-------|-------|----------------|
| Красный | Danger, stop | Luck, prosperity | Purity, fertility | Danger, evil |
| Зелёный | Nature, go | Infidelity | Islam, fertility | Islam, safety |
| Белый | Purity | Death, mourning | Mourning | Purity, peace |
| Жёлтый | Caution | Royalty, sacred | Sacred | Mourning |
| Золотой | Premium | Wealth, nobility | Divinity | Prestige |
| Синий | Trust, calm | Immortality | Krishna | Heaven, protection |

### Практические рекомендации

- Красный CTA на китайском рынке: заменить на золотой для positive actions
- Зелёный для eco/finance: безопасен в большинстве культур, но избегать на китайском для романтического контекста
- Белый фон: добавить цветные акценты для азиатских рынков
- Для MENA: зелёный = безопасный, синий = надёжный, золотой = престиж

## Step-by-step execution protocol

1. **Audit icons:** Проверить все иконки на культурную чувствительность по СТОП-листу
2. **Audit images:** Проверить изображения на культурную уместность для целевых рынков
3. **Check colors:** Проверить цветовую палитру на cultural semantics
4. **Replace problematic icons:** Заменить культурно-чувствительные иконки на универсальные
5. **Add RTL icon support:** Разделить иконки на mirrorable/no-mirror
6. **Localize hero images:** Адаптировать изображения людей для конкретных рынков
7. **Verify with cultural reviewer:** Человеческая проверка (не автоматизируется)

## Scope boundaries

### DOES
- Аудитить иконки на культурную чувствительность
- Рекомендовать безопасные универсальные иконки
- Проверять цветовую семантику для рынков
- Рекомендовать RTL-зеркалирование иконок
- Адаптировать изображения для конкретных рынков

### DOES NOT
- Создавать новые иконки (только рекомендации)
- Заменять RTL-layout обработку (используй rtl-design skill)
- Переводить текст (используй internationalization-localization skill)
- Юридическая экспертиза культурных вопросов (только awareness)

## Error handling

| Scenario | Response |
|----------|----------|
| Иконка оскорбительна для рынка | Заменить на универсальную из безопасного списка |
| Красный CTA для китайского рынка | Предложить золотой альтернативу для positive actions |
| Изображение с откровенной одеждой для MENA | Заменить на скромную версию или абстрактную иллюстрацию |
| Сова как логотип для африканского рынка | Заменить на нейтральный символ (геометрический, технический) |
