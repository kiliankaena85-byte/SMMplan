# 🎨 DesignRosetta v2.0 — Профессиональный слой UI/UX

Движок экспертных знаний для ИИ-ассистентов. Скилл не просто переводит субъективные пожелания в параметры — он думает как арт-директор: проверяет контраст, сетку, типографику, адаптив и закладывает нюансы, о которых пользователь может не знать.

---

## 🏛️ Архитектура v2.0

```
Слой 1: Язык пользователя      «сделай посолиднее» / «не читается»
Слой 2: Язык дизайна (учим)    → типографика, контраст, сетка, reflow
Слой 3: ТЗ для агента          → display-шрифт, WCAG 4.5:1, 8px grid, clamp()
Слой 4: ЭКСПЕРТНЫЙ КОНТРОЛЬ    → невидимый фильтр дилетантских ошибок
```

Слой 4 — внутренний. Пользователь его не видит, но именно он отличает «сайт от ИИ» от «сайта от арт-директора».

## 📚 БАЗА ЗНАНИЙ (Внутренний движок)

### 1. КОНТРАСТ — главный инструмент иерархии
**7 видов контраста (использовать минимум 3 осознанно):**
- **Размер:** заголовок 64px vs текст 18px (иерархия важности).
- **Вес:** bold 700 vs regular 400 (акценты в тексте).
- **Цвет:** оранжевый/акцентный на фоне (CTA, ключевые цифры).
- **Форма:** круглая кнопка vs прямые карточки (выделение действия).
- **Пространство:** элемент в пустоте (премиум, фокус).
- **Текстура:** фото/стекло vs плоский фон (глубина).
- **Направление:** диагональ или акцентная линия среди вертикалей (динамика).

**Жёсткие нормы (WCAG 2.2 AA):**
- Обычный текст: контраст $\ge 4.5:1$.
- Крупный текст ($\ge 24\text{px}$): контраст $\ge 3:1$.
- Интерактивные элементы / иконки: контраст $\ge 3:1$.
- Декоративные элементы: без норм, но иерархия обязательна.

**Правило прищуривания (Squint Test):**
> «Прищурься. Если не видно, что на экране главное — контраст не работает. Главный элемент имеет МАКСИМУМ контраста. Всё остальное — меньше.»

---

### 2. ТИПОГРАФИКА — 80% дизайна это текст
**Модульная шкала (Type Scale):**
- **1.2 (Малая терция):** сдержанно, плотно (дашборды, B2B SaaS).
- **1.25 (Большая терция):** универсально.
- **1.333 (Кварта):** выразительно (лендинги, промо-страницы).
- **1.414 (Увеличенная кварта):** драматично, контрастно.
- **1.5 (Квинта):** очень крупно (Hero-секции).

База 16–18px $\rightarrow$ каждый следующий размер = предыдущий $\times$ коэффициент.

**Параметры читабельности (жёсткие):**
- Размер body: 16–18px (никогда не использовать 14px для основного текста).
- Line-height body: 1.5–1.7.
- Line-height заголовков: 1.1–1.3.
- Длина строки: 45–75 символов (идеал 66ch).
- Letter-spacing крупных заголовков: -0.02em … -0.04em (стягивать).
- Letter-spacing мелких капсов/меток: +0.05em … +0.1em (разрежать).

**Нюанс фона и текста:**
Никогда не использовать чистый чёрный `#000` на чистом белом `#FFF` (глаза устают).
Профессионально: `#111` / `#1A1A1A` на `#FAFAF8` / `#FCFCFC`.

---

### 3. ЦВЕТ — система ролей (`@theme` Tailwind v4)
**Правило 60-30-10:**
- **60%** — фон/нейтраль (много, спокойно).
- **30%** — поверхности/вторичный (карточки, боковые панели).
- **10%** — акцент (только CTA и ключевые элементы).

**Роли в палитре (обязательный набор семантических токенов):**
`background`, `surface`, `surface-elevated`, `text-primary`, `text-secondary`, `text-disabled`, `accent`, `accent-hover`, `semantic: success/warning/error`, `border`.

**Тёмная тема — это НЕ инверсия:**
- Не `#000` фон, а приподнятые поверхности (`#0F0F10` $\rightarrow$ `#17171A` $\rightarrow$ `#1E1E22`).
- Снизить насыщенность акцентов (избегать «кислотных» цветов).
- Увеличить контраст текста.
- Тени заменять на тонкие тональные рамки или внутреннее свечение.

---

### 4. ВЫРАВНИВАНИЕ И СЕТКА — 8px Grid
**Принцип CRAP (Alignment):**
> «Каждый элемент визуально соединяется с чем-то ещё. Ничего не размещается произвольно.»

**8px Grid:**
- Все отступы, размеры, позиции кратны 8px (4px для мелких элементов).
- Шкала: `4, 8, 12, 16, 24, 32, 48, 64, 96, 128`.
- 12-колоночная сетка для макета. Контент обычно занимает 8–10 колонок.

**Выравнивание текста:**
- Длинный текст — ТОЛЬКО влево.
- По центру — только для коротких заголовков или Hero-блоков.
- Текст + иконка — выравнивание по базовой линии (`baseline`).

---

### 5. ПРОСТРАНСТВО И РИТМ
- Внутри элемента: 8–16px.
- Между связанными элементами: 8–16px.
- Между группами: 24–32px.
- Между секциями: 96–128px (desktop), 48–64px (mobile).
- Поля контейнера: 24px (mobile), 48–96px (desktop).

---

### 6. АДАПТИВ — Mobile-First & Reflow
- **Брейкпоинты:** `640px` (mobile lg), `768px` (tablet), `1024px` (laptop), `1280px` (desktop), `1536px` (wide).
- **Fluid Typography:** `font-size: clamp(1rem, 0.5rem + 1.5vw, 1.5rem);`.
- **Жёсткие нормы мобильных:**
  - Минимальная тач-цель (Touch Target): $\ge 44 \times 44\text{px}$.
  - Отступы от краёв экрана: $\ge 16\text{px}$.
  - Основной CTA: закреплён снизу (sticky bottom) в зоне большого пальца.
  - **Reflow, не shrink:** 3 колонки $\rightarrow$ 1 колонка (а не 3 узких сжатых столбца).

---

### 7. ДВИЖЕНИЕ — Микро-анимации
- **Длительности:** Микро (100–150ms), Стандарт (200–300ms), Reveal (400–600ms).
- **Easing:** Появление `ease-out`, исчезновение `ease-in`, перемещение `ease-in-out`.
- **Производительность:** Анимировать ТОЛЬКО `transform` и `opacity`. (Никогда: `width`, `height`, `top`, `left`, `margin`).
- **A11y:** Обязательная поддержка `prefers-reduced-motion`.

---

### 8. ДОСТУПНОСТЬ (a11y)
- Контраст текста $\ge 4.5:1$.
- `focus-visible` состояния у всех интерактивных элементов (не убирать `outline`).
- Семантика: `<button>` для действий, `<a>` для переходов, `<main>`, `<nav>`, `<aside>`.
- Не полагаться только на цвет при индикации ошибок.

## 🔍 НЮАНС-ДЕТЕКТОР (Anti-Amateur Matrix)

Перед выдачей промпта скилл проходит чеклист дилетантских ошибок:

| Нюанс | Проблема ИИ-верстки | Фикс в промпте / коде |
|---|---|---|
| **Pure `#000`/`#FFF`** | Чистый чёрный на белом выжигает глаза | Замена на `#1A1A1A` на `#FAFAF8` |
| **Placeholder as label** | Исчезает при вводе текста в форму | Label всегда виден, placeholder — только пример |
| **Disabled submit buttons** | Пользователь не понимает, почему кнопка не кликается | Кнопка всегда активна, фидбек на `onSubmit` (shake, auto-scroll) |
| **Missing button states** | Нет рефлекса на наведение/клик | Явное описание `hover`, `active`, `focus-visible`, `disabled` |
| **Inconsistent radius** | Разные скругления у соседних карточек | Единая шкала скруглений из дизайна |
| **Harsh single shadow** | Одна тёмная топорная тень | Многослойная мягкая тень или тональная рамка |
| **Unnoticeable links** | Ссылки не отличаются от текста | Подчёркивание или цвет + hover эффект |
| **Vague form errors** | «Что-то пошло не так» | Точное описание ошибки прямо под полем |
| **Orphan lines** | Висячие строки (одно слово на новой строке) | Текстовый контроль (`text-wrap: balance / pretty`) |
| **Decorative overload** | Иконки и кружочки ради декора | Иконка используется только если усиливает смысл |

## 🧠 ПРОТОКОЛ ПРИМЕНЕНИЯ

1. **Диагностика запроса:** Определение релевантных модулей (например, «не читается» $\rightarrow$ Типографика, «разваливается» $\rightarrow$ Адаптив + Сетка).
2. **Селекция параметров:** Из релевантных модулей берутся 2–4 конкретных параметра.
3. **Лимит когнитивной нагрузки:** 
   - Не более **4 новых терминов** пользователю (Слой 2).
   - Не более **6 экспертных параметров** в промпт агенту (Слой 3).
4. **Нюанс-детектор:** Слой 4 автоматически добавляет запреты на дилетантские мелочи.

## 📝 ШАБЛОН ЭКСПЕРТНОГО ПРОМПТА (Слой 3)

```markdown
Ты — senior веб-дизайнер и фронтенд-разработчик. 
Работаешь как арт-директор: каждое решение осознанно.

## Дизайн-система & Переменные (@theme)
- Палитра (роли): background / surface / text-primary / text-secondary / accent / border
- Контраст текста ≥ 4.5:1 (WCAG 2.2 AA)
- Фон/Текст: избегать чистого #000 на #FFF (используй #1A1A1A на #FAFAF8)

## Типографика
- Type scale: коэффициент [1.25 / 1.333], база [18px]
- Line-height: заголовки [1.15–1.2], body [1.5–1.6]
- Длина строки: ≤ 66ch (max-width)
- Letter-spacing: заголовки [-0.02em], капсы [+0.05em]

## Сетка и отступы (8px Grid)
- Отступы кратны 8px: 4, 8, 16, 24, 32, 48, 64px
- Секции: 96-128px desktop / 48-64px mobile
- Текст + иконки: выравнивание по базовой линии

## Адаптив (Mobile-First)
- Breakpoints: 640 / 768 / 1024 / 1280px
- Reflow: многоколоночные блоки встают в 1 колонку на mobile (<768px)
- Тач-цели ≥ 44×44px для всех интерактивных элементов
- Fluid type: clamp() для заголовков

## Интерактив и Состояния
- У всех кнопок/полей: hover, active, focus-visible (с сохраненным outline), disabled
- Submit-кнопка: остаётся кликабельной, при невалидности — фидбек (shake / auto-scroll к ошибке)

## НЕ ДЕЛАТЬ
- Чистый #000 на #FFF
- Placeholder вместо label в формах
- Разные border-radius у элементов одной группы
- Ужимать колонки вместо reflow в 1 колонку
- Убирать focus outline при навигации с клавиатуры
```
