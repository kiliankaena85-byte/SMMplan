# Визуальная культура РФ/СНГ — тренды, эстетика, паттерны

## When to activate

- Визуальный дизайн для российского рынка
- Адаптация западного стиля на РФ/СНГ
- Анализ визуальных трендов рунета
- Выбор стилистики для русского сегмента
- Пользователь упоминает: русская визуальная культура, рунет дизайн, тренды РФ

## ЧАСТЬ 1: ИНФОРМАЦИОННАЯ ПЛОТНОСТЬ — КЛЮЧЕВОЕ ОТЛИЧИЕ

### Почему россияне любят «плотный» дизайн

Исторически рунет формировался в условиях медленного интернета и дорогого трафика. Пользователь предпочитал загрузить одну страницу с максимумом информации, чем кликать по 5 страницам. Эта привычка сохранилась даже при быстром интернете.

**Количественные отличия от западного дизайна:**

| Параметр | Западный стандарт | РФ/СНГ стандарт |
|----------|------------------|-----------------|
| Whitespace между секциями | 80-120px | 40-60px |
| Карточек в ряд (e-commerce) | 3-4 | 4-6 |
| Полей в форме (step) | 3-5 (multi-step) | 7-12 (single step) |
| Текста above the fold | 10-20 слов | 30-60 слов |
| CTA на странице | 1-2 | 2-4 |
| Элементов в nav | 5-7 | 7-12 |

### Когда уменьшать плотность

- Премиум-сегмент: luxury, high-end B2B — воздух как сигнал качества
- Fashion-бренды: minimalism как стилистика
- Креативные агентства: воздух = свобода
- Но: масс-маркет, e-commerce, B2B SaaS — плотность = удобство

## ЧАСТЬ 2: ВИЗУАЛЬНЫЕ ТРЕНДЫ 2024-2026

### 2.1 «Манифестный» дизайн

Крупная типографика с прямолинейными заголовками-утверждениями. Отличие от западного: не «We help you grow», а «Увеличиваем продажи в 3 раза». Агрессивная конкретика вместо мягких обещаний.

Характеристики:
- Hero-заголовок: 48-72px, bold/black weight
- Подзаголовок: конкретное УТП с цифрами
- CTA: действие + выгода в одной кнопке («Получить расчёт за 5 минут»)
- Декларативный тон: «Мы —», «Наш продукт —», «Вам —»

Примеры: сайты Тинькофф Business, Selectel, Reg.ru — крупные заголовки, минимум абстракции.

### 2.2 Брутализм и антидизайн (креативный сегмент)

В fashion, art, street culture, барной сфере — намеренно «сырой» дизайн:
- Кислотные неоновые цвета на чёрном фоне
- Грубые рубленые шрифты (Arial Black, Impact, или кастомные)
- Ломаные сетки, элементы «за границей» контейнера
- Глитч-эффекты, шум, пикселизация
- «Анти-UX» как стилистический приём

Примеры: Volchok, брендинг фестивалей (Outline, Bosco Fresh), барные сайты.

### 2.3 Изометрические 3D иллюстрации

Продолжающийся тренд в fintech, edtech, B2B SaaS. Отличие от западных:
- Более насыщенные цвета (не пастельные)
- Меньше «игрушечности», больше «технологичности»
- Синяя/фиолетовая гамма доминирует
- Часто комбинируются с градиентным фоном

### 2.4 Градиенты 2.0

Градиенты вернулись, но в РФ они более насыщенные и контрастные:

Популярные комбинации:
- Фиолетово-синий (620nm -> 470nm) — fintech, SaaS
- Сине-бирюзовый (470nm -> 490nm) — корпоративный
- Красно-оранжевый (620nm -> 590nm) — e-commerce, доставка
- Зелёно-бирюзовый (520nm -> 490nm) — экологичные, здоровые

Отличие от Запада: ярче, контрастнее, менее «приглушённые».

### 2.5 «Датавиз-стиль» в продающем дизайне

Финтех и B2B активно используют дашборды и инфографику как элемент продающего дизайна. Показать цифры, графики, метрики — важнее, чем абстрактный hero.

Паттерны:
- Скрытый дашборд на скриншоте в hero
- Анимированные графики роста
- Конкретные метрики вместо иконок с текстом
- «До/После» в цифрах

### 2.6 Микроанимации и интерактив

Российский рынок догоняет западный по микроанимациям, но с отставанием в 1-2 года. В 2024-2025:
- Hover-эффекты на кнопках и карточках — стандарт
- Scroll-анимации (reveal) — растущий тренд
- Cursor-эффекты — для креативных сайтов
- Lottie-анимации — в onboarding и empty states

## ЧАСТЬ 3: ЦВЕТОВАЯ КУЛЬТУРА ПО СЕГМЕНТАМ

### 3.1 Масс-маркет (e-commerce, доставка, услуги)

- Насыщенные, яркие цвета
- Красный для скидок и срочности (агрессивнее чем на Западе)
- Оранжевый как «дружелюбный» (Ozon, Delivery Club)
- Жёлтый как «привлекающий внимание» (Яндекс, Wildberries)
- Контрастные комбинации: жёлтый+чёрный, оранжевый+белый

### 3.2 Fintech

- Синий, фиолетовый — надёжность, технологии
- Градиенты как сигнал инновационности
- Зелёный — связь со Сбербанком, финансами (использовать осторожно, не для конкурентов Сбера)
- Чёрный+золотой — премиум-сегмент (Тинькофф Premium)

### 3.3 B2B SaaS

- Синий — корпоративная надёжность
- Фиолетовый — инновационность
- Минимум ярких цветов
- Серый/графитовый как основной

### 3.4 EdTech

- Фиолетовый — лидер (Skillbox, Нетология)
- Синий — Яндекс.Практикум
- Оранжевый — энергия, мотивация
- Конкретные цвета профессий (код — зелёный, дизайн — розовый)

### 3.5 Премиум / Luxury

- Чёрный+золото/медь
- Минимум цветов, максимум воздуха
- Пастельные тона для fashion
- Фотография > иллюстрация

## ЧАСТЬ 4: СЕТКИ И LAYOUT-ПАТТЕРНЫ

### 4.1 Ширина контента

| Тип сайта | РФ max-width | Западный max-width |
|-----------|-------------|-------------------|
| Landing page | 1200-1440px | 1120-1280px |
| E-commerce | 1400-1600px | 1200-1400px |
| B2B SaaS | 1200px | 1120-1200px |
| Медиа/портал | 1280-1440px | 1120-1280px |

### 4.2 Сетка карточек

```css
/* E-commerce: плотная сетка */
.product-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 12px; /* Компактный gap */
}

/* Западный вариант для сравнения:
   grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
   gap: 24px;
*/
```

### 4.3 Sidebar навигация

Российский B2B предпочитает sidebar-навигацию:
- amoCRM: sidebar с иконками
- Битрикс24: левое меню
- 1С: классический sidebar

Западный B2B: top-navigation (Notion, Slack, Linear)

Гибрид (сверху + сбоку) растёт в популярности.

### 4.4 Hero-секции

Российский hero-паттерн:
- Крупный заголовок-утверждение
- Подзаголовок с конкретикой (цифры, сроки, гарантии)
- 2 CTA: основная (действие) + вторичная (демо/консультация)
- Справа: скриншот/иллюстрация/видео
- Под hero: полоса доверия (клиенты, цифры, награды)

### 4.5 Footer

Российский footer — юридически значимый элемент:
- Реквизиты юрлица (ИНН, ОГРН)
- Юридический адрес
- Телефон + email
- Политика конфиденциальности
- Пользовательское соглашение
- Оферта
- Способы оплаты (иконки)
- Соцсети: VK, Telegram (не Facebook/Twitter)

## ЧАСТЬ 5: ИЛЛЮСТРАЦИОННЫЕ СТИЛИ

### 5.1 Что работает в РФ

- Изометрические 3D-иллюстрации (fintech, SaaS)
- Flat-иллюстрации с локальным колоритом (разнообразие этносов, городские пейзажи)
- Фотография > стоковых иллюстраций (россияне хорошо отличают стоки)
- Пиксель-арт и ретро-стиль (в IT и гик-культуре)
- Скетчи и хэнд-мейд (в образовании и креативе)

### 5.2 Что НЕ работает

- Слишком «американские» стоковые фото (широкие улыбки, идеальные офисы)
- Пастельные «корпоративные» иллюстрации в стиле Slack/Notion
- Инди-стилистика для масс-маркета
- Абстрактный арт без чёткого сообщения

### 5.3 Фотография

- Реальные люди > модели (россияне чувствуют фальшь)
- Разнообразие: российский контекст (одежда, окружение, этносы)
- Городские пейзажи российских городов (не Нью-Йорк)
- Интерьеры в российском контексте (типичные квартиры, офисы)

## ЧАСТЬ 6: ИКОНОГРАФИКА

### 6.1 Стили иконок

- Линейные (outline) — стандарт для B2B и SaaS
- Залитые (filled) — e-commerce, масс-маркет
- Двухцветные — растущий тренд в fintech
- Изометрические — для 3D-стиля

### 6.2 Чувствительные иконки для РФ

- Медведь: может восприниматься как стереотип, использовать осторожно
- Матрёшка: клише, избегать в серьёзных проектах
- Балалайка: клише, избегать
- Купола/церкви: религиозно чувствительно
- Красная звезда: политически чувствительно
- Георгиевская лента: политически чувствительно

### 6.3 Безопасные иконки

- Абстрактные геометрические формы
- Технологические объекты
- Природные элементы
- Стандартные UI-иконки

## ЧАСТЬ 7: DARK MODE ДЛЯ РОССИЙСКОГО РЫНКА

### 7.1 Отношение к dark mode

Dark mode в РФ принял более прагматичный характер чем на Западе. Если западный dark mode — это про «эстетику» и «комфорт», то в РФ он часто про «экономию батареи» на OLED-экранах (Android доминирует) и «ночное использование» в поздние часы.

**Статистика:** 40-50% российских пользователей включают dark mode на устройствах. Для популярных приложений (Тинькофф, Сбер, VK) доля dark mode — 35-45%.

### 7.2 Цветовые палитры dark mode для РФ

```css
/* Dark mode для масс-маркета: насыщенный, не серый */
[data-theme="dark"] {
  --bg-primary: #1a1a2e;    /* Не чистый чёрный */
  --bg-surface: #16213e;    /* Глубокий синий-серый */
  --text-primary: #e8e8e8;
  --color-action: #4a9eff;  /* Яркий акцент */
  --color-danger: #ff4d4d;  /* Яркий красный */
}

/* Dark mode для fintech: премиальный */
[data-theme="dark"][data-segment="fintech"] {
  --bg-primary: #0a0a0a;
  --bg-surface: #1a1a1a;
  --color-action: #ffd700;  /* Золотой акцент */
}
```

**Отличие от западного dark mode:**
- РФ: более контрастные акценты, менее «приглушённые»
- Запад: более мягкие, приглушённые палитры
- РФ dark mode может быть «агрессивнее» — это работает

## ЧАСТЬ 8: AI-ИЗОБРАЖЕНИЯ И ОТНОШЕНИЕ РЫНКА

### 8.1 Отношение к AI-изображениям в РФ

Российский рынок быстрее принял AI-изображения чем западный. Причины: бесплатные инструменты (Kandinsky от Сбера, Шедеврум от Яндекса), меньшая озабоченность авторскими правами, мода на AI.

**Где AI-изображения работают:**
- Hero-секции B2B SaaS
- Иллюстрации для fintech (изометрия, абстракции)
- Иконки и микроиллюстрации
- Рекламные креативы

**Где НЕ работают:**
- Фотографии людей (AI-люди выглядят «неестественно» для российского глаза)
- Медицина и здоровье (нужны реальные врачи)
- Образование (нужны реальные преподаватели)

### 8.2 Российские AI-инструменты для изображений

- **Kandinsky** (Сбер): генерация изображений, бесплатно
- **Шедеврум** (Яндекс): мобильное приложение для генерации
- **FusionBrain** (МТС): генерация по текстовому описанию

### 9.2 Рекомендуемые брейкпоинты

```css
/* РФ-оптимизированные breakpoints (учитываем бюджетные Android) */
@media (min-width: 320px)  { /* Маленькие Android */ }
@media (min-width: 375px)  { /* Стандартный мобильный */ }
@media (min-width: 414px)  { /* iPhone Plus / Max */ }
@media (min-width: 768px)  { /* Планшет */ }
@media (min-width: 1024px) { /* Планшет горизонтально */ }
@media (min-width: 1280px) { /* Десктоп — начало */ }
@media (min-width: 1440px) { /* Широкий десктоп — стандарт для РФ e-commerce */ }
```

**Ключевое отличие:** 320px breakpoint критичен для РФ (дешёвые Android). На Западе часто игнорируется.

### 9.3 Производительность на бюджетных устройствах

- Избегать тяжёлых CSS-анимаций на дешёвых Android
- Не использовать backdrop-filter на устройствах < $200
- Ленивая загрузка изображений — обязательно
- Virtual scrolling для длинных списков товаров

## Step-by-step execution protocol

1. **Segment analysis:** Определить сегмент (масс-маркет, fintech, B2B, edtech, премиум)
2. **Color palette:** Выбрать палитру по сегменту (насыщенность, комбинации)
3. **Layout density:** Настроить whitespace и сетку под ожидания сегмента
4. **Hero design:** Создать манифестный hero с конкретикой
5. **Illustration style:** Выбрать стиль иллюстраций по сегменту
6. **Photography direction:** Определить направление фото (реальные люди, российский контекст)
7. **Icon style:** Выбрать стиль иконографии, проверить на чувствительность
8. **Footer design:** Включить все юридические элементы
9. **Visual regression:** Сравнить с 5-7 прямыми конкурентами на рынке

## Scope boundaries

### DOES
- Определять визуальную культуру для сегментов РФ/СНГ
- Рекомендовать цветовые палитры по сегментам
- Настраивать плотность layout для российского рынка
- Рекомендовать иллюстрационные стили
- Анализировать визуальных трендов рунета

### DOES NOT
- Создавать иллюстрации и иконки (только рекомендации по стилю)
- Заменять юридический review (только awareness по чувствительным символам)
- Проектировать для западного рынка (используй основной дизайн-скилл)
- Определять типографику (используй ru-cyrillic-typography skill)

## Error handling

| Scenario | Response |
|----------|----------|
| Западный минимализм не работает | Увеличить плотность, добавить конкретику, убрать «воздух» |
| Иллюстрации кажутся «чужими» | Перейти на реальную фотографию в российском контексте |
| Пастельная палитра не конвертирует | Увеличить насыщенность, добавить контрастные акценты |
| Брутализм не подходит сегменту | Это тренд только для креативных ниш — использовать манифестный дизайн |
| Пользователь не видит CTA | Добавить контраст, увеличить размер, конкретизировать текст кнопки |
