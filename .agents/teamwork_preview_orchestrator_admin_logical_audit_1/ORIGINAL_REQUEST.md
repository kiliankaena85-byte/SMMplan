## Requirements

### R1. Декомпозиция админ-панели
Команда агентов должна изучить директории `src/app/admin` и `src/actions/admin` и разбить админ-панель на четкие логические модули (например, Пользователи, Заказы, Провайдеры, Услуги, Маркетинг, Настройки).

### R2. Анализ User Flows
Для каждого логического модуля необходимо отследить пользовательские сценарии (User Flows) — от интерфейса (React Server/Client Components) до серверных действий (Server Actions) и запросов к базе данных (Prisma).

### R3. Поиск проблем и составление отчета
В процессе трейсинга сценариев команда должна выявлять "логические дыры", неработающий код (заглушки) и потенциальные уязвимости. Все находки должны быть собраны в единый итоговый отчет. Отчет не должен содержать исправления кода — только диагностику.
