# 🔗 MCP Server Health Check — Проверка здоровья MCP-серверов

Скилл `mcp-server-health-check` предназначен для тестирования доступности и проверки конфигурации внешних MCP (Model Context Protocol) серверов и их инструментов, используемых ИИ-агентом при выполнении задач.

## When to activate

| Ситуация / Триггер | Описание | Действие |
| :--- | :--- | :--- |
| **Ошибки StitchMCP** | При сбоях вызова инструментов StitchMCP или таймаутах | Запустить пинг серверов для диагностики |
| **Инициализация окружения** | При первом запуске агента в новой среде | Проверить готовность всех шлюзов |
| **Запрос пользователя** | По прямому указанию проверить состояние интеграций | Выполнить полный аудит конфигураций |

## Scope boundaries

### В рамках скилла
- Пинг и отправка тестовых запросов к зарегистрированным MCP серверам.
- Проверка валидности JSON схем зарегистрированных MCP инструментов.
- Формирование отчета об ошибках тайм-аута и недоступности сети.

### Вне рамок скилла
- Автоматический перезапуск упавших локальных Docker-контейнеров с серверами.
- Изменение файлов конфигурации `mcp_config.json` без одобрения пользователя.
- Работа с серверами, не прописанными в системном профиле окружения.

## Step-by-step execution protocol

1. **Предварительный сбор**: Считайте список доступных в системе серверов и их порты/пути.
2. **Запуск проверки**: Выполните команду проверки доступности MCP-серверов:
   ```bash
   npx tsx .agent/skills/mcp-server-health-check/scripts/check-mcp.ts
   ```
3. **Анализ результатов**: Ознакомьтесь со статусами (SUCCESS/FAILED) для каждого сервера в выводе скрипта.
4. **Устранение неполадок**: Если сервер недоступен, проверьте статус локальных процессов NodeJS, настройки сети или обновите файлы конфигурации.

## Error handling

- **Таймаут подключения**: Если сервер не отвечает в течение 5 секунд, он помечается как `FAILED`. Проверьте интернет-соединение или статус хоста.
- **Неверный JSON схемы**: Если схема инструмента невалидна, скрипт выводит предупреждение о повреждении схемы. Запросите повторную загрузку конфигурации.
- **Отсутствие прав доступа**: Если системный порт заблокирован брандмауэром, выведите рекомендацию о добавлении в исключения.
