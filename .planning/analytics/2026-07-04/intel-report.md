# 🕵️ INTEL Report — Smmplan (2026-07-04)

## 1. Анализ интеграций с SMM-провайдерами
* Проект интегрирован с API SMM-панелей (по протоколу Gear/Standard SMM).
* Идентификация услуг и синхронизация тарифов происходят по расписанию через задачи воркеров.
* **Вендорные риски (Vendor Lock-in):** Основной объем услуг привязан к тестовым и демонстрационным провайдерам. Для продакшена требуется диверсификация поставщиков услуг.

## 2. Мониторинг стабильности API
* Все вызовы к провайдерам осуществляются через безопасную обертку с таймаутами и логированием ошибок.
* Авто-маржинальный воркер защищает систему от финансовых потерь, отслеживая расхождения курсов валют и изменения базовых цен у провайдеров.

## 3. Рекомендации
* **Shadow Catalog:** КАТЕГОРИЧЕСКИ запрещено импортировать сырые прайс-листы провайдеров (более 5000 услуг) напрямую в PostgreSQL. Использовать промежуточный Redis-буфер и инструмент ручного черри-пикинга (Cherry-Pick Import).
* **Резервные маршруты:** Настроить автоматическое переключение на резервного провайдера для одной и той же услуги, если у основного провайдера нулевой баланс или происходят сбои API.
