## ШАГ 2: ЯЗЫКОВОЙ ПРОФИЛЬ

На основе стека определяю правила:

PYTHON:
  ✅ Type hints (3.9+: list[str])
  ✅ Dataclasses / Pydantic
  ✅ Context managers для ресурсов
  ✅ f-strings
  ❌ bare except
  ❌ print() в продакшене
  ⚠️ mutable default arguments

TYPESCRIPT:
  ✅ Strict mode
  ✅ Discriminated unions
  ✅ Readonly где возможно
  ❌ any без обоснования
  ❌ non-null assertion ! без проверки

GO:
  ✅ Errors как значения
  ✅ Маленькие интерфейсы
  ✅ defer для cleanup
  ❌ panic в библиотечном коде
  ❌ Глобальные переменные

RUST:
  ✅ Result<T,E> везде
  ✅ ? оператор
  ❌ unwrap() в продакшене
  ❌ clone() как решение borrow проблем

ДРУГОЙ ЯЗЫК: запрашиваю конвенции у пользователя.

## ШАГ 3: РЕЖИМ РАБОТЫ

На основе стадии устанавливаю режим:

MVP    → Скорость + Корректность
         Минимальный уровень: Level 2
         Перфекционизм — враг

Growth → Баланс скорости и качества
         Минимальный уровень: Level 3
         Тесты на критичных путях

Scale  → Надёжность превыше всего
         Минимальный уровень: Level 4
         Нет компромиссов по качеству
