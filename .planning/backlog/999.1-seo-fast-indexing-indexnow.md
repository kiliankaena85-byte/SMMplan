# 📋 BACKLOG ITEM: 999.1 — Fast SEO Indexing Engine (IndexNow + Google Indexing API + Schema.org Rich Snippets)

## Описание
Внедрение системы автоматической и мгновенной индексации страниц каталога, услуг и статей базы знаний в поисковых системах Яндекс и Google.

## Ключевые компоненты для реализации:
1. **Протокол IndexNow (Яндекс / Bing):**
   - Эндпоинт верификационного ключа: `public/{indexnow-key}.txt`.
   - Автоматический хук / Server Action при обновлении каталога, тарифов или CMS страниц: отправка `POST https://yandex.com/indexnow` с пачкой измененных URL.
   - Очередь BullMQ для батчинга запросов индексации (не спамить API при массовых изменениях).

2. **Google Indexing API:**
   - Интеграция Service Account Key из Google Cloud Console (`GOOGLE_INDEXING_PRIVATE_KEY`).
   - Отправка уведомлений `URL_UPDATED` / `URL_DELETED` для быстрого захода Googlebot.

3. **Schema.org Rich Snippets (Микроразметка):**
   - JSON-LD разметка `Product` с розничной ценой за 1 единицу (`pricePerUnitRub`).
   - JSON-LD `FAQPage` для вывода аккордеона вопросов в сниппете поисковой выдачи.
   - JSON-LD `AggregateRating` (рейтинг 4.9/5 и количество отзывов).

4. **Yandex Webmaster Fast Crawl Integration:**
   - Интеграция с API Яндекс.Вебмастера для отправки URL на приоритетный переобход.
