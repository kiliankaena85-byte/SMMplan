# Задача для Маркетолога: Ренейминг категорий каталога

**Дата постановки:** 2026-06-23
**Приоритет:** Средний
**Контекст:**
В текущем каталоге услуг (например, ВКонтакте) используются длинные и малоинформативные названия категорий:
- "👨‍👩‍👧‍👦 Подписчики / Участники"
- "👥 Вступление в группы / чаты"

Эти категории визуально перегружают интерфейс, дублируют смысл и могут путать пользователя (разница между "подписчиками" и "вступлением в группы" не очевидна для обычного клиента).

**Что нужно сделать:**
1. Провести аудит текущих названий категорий в базе данных (Таблица `Category`).
2. Сократить названия, сделав их более ёмкими и конверсионными.
3. Убрать визуальный шум (возможно, оставить только короткий текст и эмодзи без длинных двойных названий со слешем).
4. Объединить дублирующие по смыслу категории в одну (например, свести всё в "Подписчики").
5. Подготовить таблицу маппинга: `Старое название -> Новое название` для заливки изменений в БД.

**Ожидаемый результат:**
Список новых, лаконичных названий категорий для улучшения UX и повышения конверсии.
