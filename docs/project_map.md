# Project Map: «Умный Dripfeed 2.0»

Этот документ содержит ссылки на 5 ключевых файлов в проекте Smmplan, которые непосредственно задействованы в интеграции модуля Умного Dripfeed 2.0. Он служит точным путеводителем (Project Map) для безопасного пошагового внедрения без поломки основных бизнес-процессов платформы.

---

## Ключевые файлы системы Smmplan

### 1. 🗄️ База данных и схемы моделей
* **Путь**: [prisma/schema.prisma](file:///d:/SMM_plan_2/prisma/schema.prisma)
* **Роль**: Определяет структуру таблиц PostgreSQL. Именно сюда добавляются модели `SmartCampaign`, `SmartTask`, `SmartExecution`, `ServiceSmartConfig`, `SmartSnapshot` и `SmartDetectedUser` в рамках Спринта 1.

### 2. 🛒 Оформление заказов и Server Action
* **Путь**: [src/actions/order/checkout.ts](file:///d:/SMM_plan_2/src/actions/order/checkout.ts)
* **Роль**: Главный мутатор оформления заказов со стороны клиента. Здесь происходит Zod-валидация, списание средств, проверка лимитов и роутинг провайдеров. Сюда будет встроен перехватчик (хук), перенаправляющий умные заказы в `SmartDripService`.

### 3. 📦 Сервис бизнес-логики заказов
* **Путь**: [src/services/core/order.service.ts](file:///d:/SMM_plan_2/src/services/core/order.service.ts)
* **Роль**: Управляет жизненным циклом заказов в БД (создание, отмена, перезапуски, возврат средств). Будет задействован для отслеживания статусов и связывания кампаний с фактами выполнения порций.

### 4. ⚙️ Фоновые BullMQ-воркеры
* **Путь**: [src/workers/index.ts](file:///d:/SMM_plan_2/src/workers/index.ts)
* **Роль**: Главный менеджер фоновых очередей платформы (заказы, докрутки, синхронизации). Сюда мы интегрируем новый воркер планировщика порций `dripfeedWorker`.

### 5. 🎨 Фронтенд оформления заказов (Клиент)
* **Путь**: [src/components/orders/SmartOrderForm.tsx](file:///d:/SMM_plan_2/src/components/orders/SmartOrderForm.tsx)
* **Роль**: Компонент формы заказа на фронтенде для клиентов. В эту форму мы внедрим переключатель «Умный Dripfeed 2.0» с выбором дней и показом порций.
