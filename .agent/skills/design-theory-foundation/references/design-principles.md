# 7 функций графического дизайна

> Источник: Соколов А.А., «Графический дизайн (основы профессии)», 2011

1. **Стимулирование** — побуждение к действию (CTA, конверсионные элементы)
2. **Информирование** — передача данных (контент, features, спецификации)
3. **Организация** — структурирование информации (навигация, layouts, журналы)
4. **Локализация / Навигация** — пространственная ориентация (wayfinding, меню, breadcrumbs)
5. **Идентификация** — узнавание бренда (логотип, фирменный стиль)
6. **Притягивание внимания** — первая точка контакта (hero, баннеры)
7. **Визуальное удовольствие** — эстетическое удовлетворение (анимации, типографика)

**Правило для ИИ:** Каждый экран должен проходить проверку — какие из 7 функций он выполняет? Если ни одной — элемент лишний. Если более трёх — когнитивная перегрузка.

# 4 принципа CRAP

## Контраст
Суть контраста в избегании элементов, которые являются одинаковыми. Если элементы неодинаковы — нужно сделать их РАЗНЫМИ. Слабое различие создаёт ощущение небрежности. Либо делайте элементы явно разными, либо явно одинаковыми.

## Повторение
Повторяйте визуальные элементы дизайна на протяжении всей работы: цвета, формы, текстуры, пространственные отношения, толщины линий, шрифты, размеры, графические концепции.

## Выравнивание
Ничто не должно располагаться на странице произвольно. Каждый элемент должен иметь визуальную связь с другим элементом на странице.

## Приближенность (proximity)
Связанные друг с другом элементы должны быть плотно сгруппированы. Расстояние между элементами — это информация.

# 5 признаков композиции

1. **Повторение целого и его частей** — утверждающий основной признак целостности
2. **Соподчинённость** — упорядоченность всех элементов, обеспечивающая последовательность восприятия
3. **Соразмерность** — установленная единая мера соизмерения признаков элементов
4. **Равновесие** — уравновешенность целого и всех его частей относительно пространственных осей
5. **Единство** — обобщающий признак и принцип композиции

# Эмоциональная семантика цвета

- Жёлтый — светоносный, радостный
- Нежно-голубой — возвышенный
- Ярко-розовый — экстравагантный, претенциозный
- Зелёный — открытый, приветливый
- Серый — нейтральный, безликий
- Тёмно-голубой — насыщенный, благородный
- Коричневый — тяжёлый, земной
- Фиолетовый — тёмный, мистический
- Чёрный — графичный, весомый, строгий
