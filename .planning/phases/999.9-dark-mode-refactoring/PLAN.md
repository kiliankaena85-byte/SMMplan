# План реализации: Рефакторинг UX/UI Темной Темы Smmplan (Phase 999.9)

Этот документ описывает технический план по полному переходу на премиальную темную тему (Dark Mode 2.0) с минимизацией визуального бардака, устранением FOUC-эффектов, настройкой контрастности по WCAG AAA/AA и защитой от специфических багов Chrome Autofill в темном режиме.

---

## 1. UX-Анализ текущего состояния (As-Is)
- **Отсутствие темных Tailwind v4 токенов**: Переменные темы в `globals.css` определены статически для светлой темы. При переключении на темный режим (`sky-dark`, `emerald-dark`, `violet-dark`) базовый фон `bg-background` и карточки `bg-card` остаются светлыми, создавая слепящий контрастный диссонанс с темными компонентами HeroUI.
- **Неконтрастные акцентные цвета**: Зеленый (`emerald-700`) и фиолетовый (`violet-600`) акценты используются как для светлых, так и для темных тем. На темном фоне темно-зеленые кнопки сливаются, нарушая требования WCAG AA (контрастность < 3:1).
- **Слепящий Chrome Autofill в темном режиме**: Фикс автозаполнения жестко задает темно-синий цвет шрифта (`#0f172a`), из-за чего в темной теме введенный текст становится невидимым.

---

## 2. Предлагаемое решение (To-Be)

Мы перейдем к безупречному кросс-темному стилю в Tailwind v4 с использованием CSS-first переменных.

### 2.1 Групповой селектор темной темы в `globals.css`
Мы определим все базовые токены Tailwind v4 в темном режиме для группы классов `.dark`, `.sky-dark`, `.emerald-dark`, `.violet-dark` и `[data-theme*="dark"]`:
- **Фон**: `#020617` (slate-950) — глубокий, мягкий сине-черный цвет.
- **Карточки / Поверхности (Surface L1)**: `#0f172a` (slate-900) — обеспечивает визуальный подъем (Elevation).
- **Границы**: `#1e293b` (slate-800) — тонкие технологичные рамки.
- **Приглушенный текст / Подсказки**: `#94a3b8` (slate-400).

### 2.2 Разделение акцентных тем (Emerald & Violet)
Мы разделим стили темных и светлых вариантов акцентов:
- В **Emerald Light**: `--color-primary` = `#047857` (emerald-700), `--color-secondary` = `#d1fae5`.
- В **Emerald Dark**: `--color-primary` = `#10b981` (emerald-500 — десатурированный, яркий зеленый), `--color-secondary` = `#064e3b` (emerald-950), `--color-secondary-foreground` = `#34d399`.
- В **Violet Light**: `--color-primary` = `#7c3aed` (violet-600), `--color-secondary` = `#ede9fe`.
- В **Violet Dark**: `--color-primary` = `#a78bfa` (violet-400), `--color-secondary` = `#2e1065` (violet-950), `--color-secondary-foreground` = `#c084fc`.

### 2.3 Адаптация Chrome Autofill для темной темы
Добавим медиа-селектор в `@layer base` для переопределения `-webkit-text-fill-color` в темных темах на `#f8fafc`.

## 3. Пошаговый план выполнения

### Шаг 1: Обновление `src/app/globals.css`
Внедрить CSS-переменные для темной темы и разделенные акцентные цвета.

### Шаг 2: Тестирование и валидация
- Сделать e2e Playwright-скриншоты в теме `sky-dark` с помощью скрипта `scripts/synthetic-ux-lab/capture-all-pages.ts`.
- Проверить типы TypeScript (`npx tsc --noEmit`).
- Запустить Vitest тесты (`npm run test`).
- Запустить Next.js сборку (`npm run build`).

### Шаг 3: Обновление `task.md` и `walkthrough.md`
Зафиксировать результаты рефакторинга темной темы.
