## 2. Logic Chain
- The test suite mocks the GraphRAG and Gemini APIs using Vitest's `vi.stubGlobal` to assert behavior deterministically.
- Running the tests directly from the repository root via `npx vitest run teamwork_projects/round_table_experts/test_round_table.ts` fails because the root `vitest.config.ts` has `setupFiles: ['./test/setup.ts']` and `unstubGlobals: true`, which clears mock stubs between tests and causes mock fetches to fall back to real network requests, triggering connection resets for `api.gemini.local`.
- Running the tests with prefix or within the directory `d:\SMM_plan_2\teamwork_projects\round_table_experts` ensures that the project-local `vitest.config.ts` is used, which does not have database-wiping or mock-clearing setups.
- Under the local configuration, 100% of the 11 tests pass, verifying the correctness of context compression, self-correction loop, and Deep Researcher multi-source validation (rejection of fake/unvalidated facts and ingestion of validated facts).

## 3. Caveats

- The GraphRAG server (normally running on port 8100) is mocked in the tests to guarantee consistent execution, but was verified to work correctly with real API payloads.
