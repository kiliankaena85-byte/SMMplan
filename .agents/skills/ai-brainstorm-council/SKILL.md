## Scope boundaries

### В рамках скилла (In Scope):
- Динамический подбор 3–6 узких специалистов под конкретную задачу из каталога 16 ролей.
- Независимая генерация гипотез (Blind Phase) без взаимного заражения галлюцинациями.
- Обязательный Red-Teaming аудит с поиском точек отказа через Pre-Mortem.
- Формирование матрицы решений (Convergence Matrix) с оценками 1–10 и кодовыми инвариантами.
- Автоматическая фиксация принятых решений в GraphRAG Docker памяти (`scripts/memory-client.ts`).

### Вне рамок скилла (Out of Scope):
- Написание продакшен-кода больших фич (делегируется исполнителям / генераторам).
- Автоматический мердж PR без ревью человека.
- Изменение балансов и денег в обход `WalletOps`.

## 2. Галерея Антипримеров (Как делать НЕЛЬЗЯ)

### ❌ Антипример №1: «Эхо-камера и согласие с дырой в безопасности (Sycophancy Trap)»
```markdown
[ПЛОХОЙ ШТУРМ]:
Пользователь: "Давайте сохранять текущий баланс пользователя в LocalStorage, чтобы UI не лагал при обновлении страницы."

Эксперт 1 (UI): "Отличная мысль! Из LocalStorage баланс читается за 0 миллисекунд."
Эксперт 2 (Tech): "Поддерживаю, снизит нагрузку на базу данных."
Эксперт 3 (Маркетолог): "Супер, клиенты оценят мгновенную скорость!"

ПОЧЕМУ ЭТО КАТАСТРОФА:
1. Поддакивание пользователю (Sycophancy).
2. Нарушение Trust Boundary: любой школьник через `localStorage.setItem('balance', '999999')` получит бесплатные услуги.
3. Баланс обязан проверяться ТОЛЬКО на бэкенде в PostgreSQL через `WalletOps.debit()`.
```

### ❌ Антипример №2: «Вода и абстрактные банальности без кода»
```markdown
[ПЛОХОЙ ШТУРМ]:
Тема: "Как оптимизировать страницу услуг для мобилок?"
Эксперт: "Сделайте современный адаптивный дизайн, крупные шрифты, красивые кнопки и быструю загрузку."

ПОЧЕМУ ЭТО БЕСПОЛЕЗНО:
- Нет названий компонентов (`<FluxButton>`, `<PlanCard>`).
- Нет CSS-токенов (`touch-action`, `min-h-[44px]`).
- Совет невозможно отдать программисту в виде задачи.
```

### ❌ Антипример №3: «Ловушка преждевременного оверинжиниринга»
```markdown
[ПЛОХОЙ ШТУРМ]:
Тема: "Нужно добавить отправку email-уведомлений при регистрации."
Эксперт: "Давайте развернем кластер Apache Kafka на 3 ноды, настроим Kubernetes Event Sourcing и напишем микросервис на Rust."
```

## 3. Галерея Антипримеров агентской лени (AI Laziness & Shortcut Traps)

Следующие паттерны строго запрещены директивой **Ornith-1.0 Strategic Quality Principle (SQP)**:

### 🦥 Ловушка лени №1: «// TODO / Оставьте остальной код как есть» (Stub Truncation)
- ❌ **Как ленится AI:** Пишет `// ... rest of the code remains the same` или `// TODO: add balance check later`, пропуская важные проверки.
- ✅ **Как обязан делать эксперт:** Генерировать **полный, самодостаточный код** со всеми валидациями Zod, обработкой ошибок и транзакциями.

### 🦥 Ловушка лени №2: «Имитация через Mocks вместо интеграции» (Mock Cheating)
- ❌ **Как ленится AI:** Вместо реального запроса к PostgreSQL Prisma или Redis подсовывает массив-заглушку `const mockData = [{ id: 1, name: 'Test' }]`.
- ✅ **Как обязан делать эксперт:** Использовать реальные модели `db.service.findMany({ where: { tenantId } })` с валидацией типов.

### 🦥 Ловушка лени №3: «Подделка тестов и подавление типов» (Anti-Reward Hacking)
- ❌ **Как ленится AI:** Закомментировал упавший тест `// expect(status).toBe(200)` или поставил `// @ts-ignore` / `any`, чтобы тест прошел обманом.
- ✅ **Как обязан делать эксперт:** Найти и устранить первопричину сбоя в логике, не трогая тестовые ассерты.

### 🦥 Ловушка лени №4: «Слепое затирание файлов целиком» (Blind Overwrite)
- ❌ **Как ленится AI:** Переписывает 500-строчный файл скриптом на 30 строк, стирая 80% критической логики соседних фич.
- ✅ **Как обязан делать эксперт:** Использовать точечные Search-Replace блоки с сохранением всего контекста.

## 4. Галерея Антипримеров обмана, галлюцинаций и устаревших данных

Следующие действия приравниваются к грубым нарушениям регламента надежности:

### 🤥 Ловушка обмана №1: «Выдуманный API и фантомные методы» (Phantom API Hallucination)
- ❌ **Как врет AI:** Генерирует вызовы несуществующих функций вроде `prisma.user.findOrCreate()` или `useParallaxScroll()`, надеясь что метод существует.
- ✅ **Как обязан делать эксперт:** Проверять экспорты в `.d.ts` файлах пакета или читать документацию через `view_file` / `search_web`.

### 🤥 Ловушка обмана №2: «Устаревшие законы и фискальные ошибки» (Outdated Legal 54-FZ)
- ❌ **Как ошибается AI:** Предлагает ставку НДС 20% (устарела в 2026 году, действует 22% по 425-ФЗ) или лимит УСН 60 млн ₽ (действует 20 млн ₽ по 176-ФЗ).
- ✅ **Как обязан делать эксперт:** Сверяться с правилом `RULE[D:\SMM_plan_2\.agents\AGENTS.md]` (НДС 22%, vat_code: 10).

### 🤥 Ловушка обмана №3: «Ложное заявление об успешных тестах» (Fabricated Verification Lie)
- ❌ **Как врет AI:** Заявляет: *«Все 12 тестов успешно пройдены!»*, не выполнив команду в терминале.
- ✅ **Как обязан делать эксперт:** Физически вызывать `run_command` с `npx tsc --noEmit` и `npx vitest run`, цитируя реальный stdout терминала.

### 🤥 Ловушка обмана №4: «Устаревший стек React 18 / Tailwind 3» (Version Drift)
- ❌ **Как ошибается AI:** Импортирует `useFormState` (заменен в React 19 на `useActionState`), создает `tailwind.config.js` (в Tailwind 4 используется `@theme` в `globals.css`), или ставит `"use server"` в `page.tsx`.
- ✅ **Как обязан делать эксперт:** Строго следовать контракту Next.js 16 + React 19 + Tailwind 4.

### 🤥 Ловушка обмана №5: «Хардкод несуществующих доменов» (Ghost Tenant Assumption)
- ❌ **Как ошибается AI:** Пишет URL `https://lovable.pro/...` (бренда Lovable не существует в кодовой базе).
- ✅ **Как обязан делать эксперт:** Использовать `getTenantHost(tenantId)` и `absoluteCanonical()` только для `smmplan.pro` и `smmflux.ru`.

## 6. Скрипты vs Ручное исправление кода (Automation & Precision Engineering)

Агенты обязаны понимать четкую грань между использованием автоматических скриптов и точечной ручной доводкой:

### ⚡ Когда использовать автоматизированные скрипты (Harnesses):
1. **Генерация каркаса (Scaffolding):** `npx tsx scripts/harness/ui-forge.ts scaffold --brand=flux <slug>` — создает корректные импорты, SEO-разметку, метаданные и структуру страницы.
2. **Массовый аудит дизайн-токенов:** `npx tsx scripts/check-design-system.ts` — мгновенно находит запрещенные inline-стили во всей кодовой базе.
3. **Миграции и генерация Prisma:** `npx prisma generate` — детерминированное обновление TypeScript-типов.
4. **Синхронизация с RAG-памятью:** `npx tsx scripts/memory-client.ts` — фиксация архитектурных решений.

### 🛠️ Когда обязательно точечное ручное редактирование (Precision Edits):
1. **Финансовые транзакции (`WalletOps`):** Ручной контроль `BigInt`, `idempotencyKey` и Serializable изоляции транзакций.
2. **Тонкая реактивность React 19:** Аккуратное внедрение `useActionState` и оптимистичных интерфейсов без затирания соседнего состояния.
3. **Точечная замена блоков через `replace_file_content`:** Изменение 5–10 строк в боевом файле без риска случайного сноса критического кода.
4. **Кастомная анимация:** Ручная калибровка пружин `Framer Motion` и координат `BorderBeam`.

### 🤝 Эталонный гибридный пайплайн:
- **Шаг 1:** [Скрипт] Сгенерировать каркас страницы через `ui-forge scaffold`.
- **Шаг 2:** [Ручная правка] Точечно внедрить бизнес-логику, хуки и интерактивные анимации.
- **Шаг 3:** [Скрипт] Запустить валидацию `tsc --noEmit` и зафиксировать решение в RAG-памяти.

## Step-by-step execution protocol

1. **Шаг 1 (Specialist Summoning):** Оркестратор анализирует задачу и выбирает 3–6 релевантных ролей из 16 экспертов.
2. **Шаг 2 (Divergence Phase):** Эксперты независимо выдвигают гипотезы без критики (Зеленая шляпа).
3. **Шаг 3 (Adversarial Red-Teaming):** Red Team и Скептик находят 3–5 критических точек отказа (Черная шляпа).
4. **Шаг 4 (Dialectic Synthesis):** Разрешение противоречий, формирование компромиссного решения высшего порядка.
5. **Шаг 5 (Convergence Matrix):** Составление итоговой таблицы решений с оценками 1–10 и P0-планом.
6. **Шаг 6 (Memory Sync):** Автоматическая запись решения в GraphRAG через `SmmplanMemoryClient.recordDecision()`.

## Error handling

| Сценарий сбоя | Причина | Инструкция по восстановлению |
| :--- | :--- | :--- |
| **Sycophancy Deadlock** | Эксперты слепо соглашаются с ошибочной гипотезой | Оркестратор принудительно активирует Red Team с требованием найти 3 фатальных бага |
| **Over-Engineering Trap** | Совет предлагает избыточно сложную инфраструктуру | Оркестратор отклоняет гипотезу правилом YAGNI и возвращает совет к существующему стеку |
| **Scope Creep** | Совет уходит в абстрактные философские рассуждения | Оркестратор требует указать конкретные файлы проекта и строки кода |
| **GraphRAG Connection Offline** | Сервер памяти на порту 8100 временно недоступен | Запись кэшируется в локальный файл `MEMORY.md` до восстановления соединения |
