# viewport-responsive-density (High-Density Dashboard Standard)

## 🛑 HARD INVARIANTS
1. **Zero Horizontal Scroll:** Любой дашборд обязан на 100% умещаться по ширине в экран (1366px ноутбуки, 1920px десктопы). Запрещены фиксированные `min-w-[1000px]`.
2. **Лимит колонок:** В таблицах админки — максимум 7–9 видимых колонок. Второстепенные метаданные выносятся в Tooltip, Popover или модальное окно.
3. **Канонические ширины колонок:**
   - ID: `w-16 font-mono text-[11px]`, Дата: `w-24 text-xs`, Статус: `w-28`, Сумма: `w-24 text-right font-medium`, Действия: `w-20 text-right`.
4. **Текстовая защита:** Все текстовые поля (название услуги, email, ссылка) ограничены `max-w-[160px] sm:max-w-[220px] truncate` в связке с `min-w-0`.
5. **Master-Detail Split:** При разделении экрана на список и детали на экранах $< 1024\text{px}$ используется полноэкранный переход, на $\ge 1024\text{px}$ — сплит 40/60.
