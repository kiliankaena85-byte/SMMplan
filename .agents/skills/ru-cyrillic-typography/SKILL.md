# Кириллическая типографика — шрифты, текст, специфика

## When to activate

- Выбор шрифтов для русскоязычного проекта
- Настройка типографики для кириллицы
- Проверка text expansion для русского языка
- Типографские символы (кавычки-ёлочки, тире, ё)
- Пользователь упоминает: кириллица, русские шрифты, типографика, переносы, ё

## ЧАСТЬ 1: TEXT EXPANSION — РУССКИЙ ДЛИННЕЕ АНГЛИЙСКОГО

### 1.1 Expansion rate

Русский текст на 15-20% длиннее английского при переводе. Это критично для:
- Кнопок: «Submit» (6) -> «Отправить» (9, +50%)
- Навигации: «About» (5) -> «О компании» (9, +80%)
- Форм: «First name» (10) -> «Имя» (3, -70% — но с label может быть длиннее)

### 1.2 Примеры expansion

| English | Русский | Изменение |
|---------|---------|-----------|
| Settings | Настройки | +13% |
| Checkout | Оформление заказа | +140% |
| Search | Поиск | +20% |
| Save | Сохранить | +100% |
| Delete | Удалить | +67% |
| Cancel | Отмена | +0% |
| Sign in | Войти | -25% |
| Sign up | Зарегистрироваться | +200% |
| Contact us | Связаться с нами | +55% |
| Add to cart | В корзину | -10% |

### 1.3 Design решения

```css
/* Кнопки: автоподбор ширины */
.button {
  width: auto;
  min-width: 80px;
  max-width: 280px; /* Увеличить max-width для русского */
  padding-inline: var(--space-lg);
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

/* Навигация: допускаем перенос */
.nav-item {
  max-width: 160px;
  overflow: hidden;
  text-overflow: ellipsis;
}
```

## ЧАСТЬ 2: ШРИФТЫ С КИРИЛЛИЦЕЙ

### 2.1 Санкционированные шрифты (работают в РФ)

С 2022 года многие западные шрифтовые сервисы ограничили доступ из РФ. Рекомендации:

**Google Fonts (доступен):**
- Inter — лучший sans-serif с кириллицей
- Noto Sans / Noto Serif — полная поддержка
- PT Sans / PT Serif — российские шрифты от ParaType
- Roboto — стандарт Android
- Montserrat — популярный для заголовков
- Open Sans — универсальный
- IBM Plex Sans — от IBM, кириллица

**Российские шрифтовые сервисы:**
- ПараТайп (paratype.com) — российский шрифтовый найдёр
- TypeType (typetype.ru) — кириллические шрифты
- ABC-Design (abcdesign.ru) — российская студия
- Шрифты от студии Artem Gorbunov

**Системные стеки:**
```css
/* Для macOS + Windows с кириллицей */
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto,
  'Helvetica Neue', Arial, sans-serif;

/* Для Linux с кириллицей */
font-family: 'Roboto', 'Noto Sans', 'Liberation Sans', sans-serif;
```

### 2.2 Font stack рекомендация

```css
:root {
  --font-body: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  --font-heading: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  --font-mono: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;
}
```

### 2.3 Веб-шрифты: подключение

```css
/* Предзагрузка критических шрифтов */
<link rel="preload" href="/fonts/inter-cyrillic.woff2" as="font" type="font/woff2" crossorigin>

@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-cyrillic.woff2') format('woff2');
  font-weight: 100 900;
  font-display: swap;
  unicode-range: U+0400-045F, U+0490-0491; /* Кириллица */
}
```

## ЧАСТЬ 3: LINE-HEIGHT И МЕЖСТРОЧНОЕ РАССТОЯНИЕ

### 3.1 Рекомендуемые значения

Кириллический текст требует немного больше line-height чем латиница из-за диакритических знаков (й, ё) и заглавных букв.

| Элемент | Латиница | Кириллица |
|---------|----------|-----------|
| Body text | 1.5 | 1.55-1.6 |
| Heading | 1.2 | 1.25 |
| Small text | 1.4 | 1.45 |
| UI labels | 1.3 | 1.35 |

### 3.2 CSS настройка

```css
:root {
  --line-height-body: 1.6;    /* Для русского текста */
  --line-height-heading: 1.25;
  --line-height-tight: 1.35;
  --line-height-loose: 1.75;
}

:lang(ru) {
  line-height: var(--line-height-body);
}
```

## ЧАСТЬ 4: ТИПОГРАФСКИЕ СИМВОЛЫ

### 4.1 Кавычки-ёлочки

В русском языке используются кавычки-ёлочки: « » (не " " и не „ ")

```css
:lang(ru) q {
  quotes: "\00AB" "\00BB" "\00AB" "\00BB";
}

/* Или в HTML: */
<p>Он сказал: <q>Привет</q></p>
<!-- Результат: Он сказал: «Привет» -->
```

### 4.2 Тире

- Длинное тире (—): для разделения частей предложения
- Короткое тире (–): для диапазонов (10–20)
- Дефис (-): для сложных слов (по-русски)

```css
:lang(ru) {
  /* Автоматическая замена дефисов на тире */
  hyphens: auto;
}
```

### 4.3 Буква Ё

- Всегда использовать ё в UI-тексте, формах, кнопках
- В длинных текстах допускается замена на е (кроме случаев двусмысленности: всё/все, совершенный/совершённый)
- В поиске: игнорировать различие е/ё

### 4.4 Неразрывные пробелы

Обязательные места для неразрывного пробела (U+00A0):
- Между цифрой и единицей: 10 кг, 2024 г.
- Между инициалами и фамилией: А. С. Пушкин
- Перед предлогами: в Москве, на столе
- После тире в диалогах: — Привет!
- Между сокращениями: т. д., т. е., и т. д.

```css
/* Автоматическая расстановка неразрывных пробелов — через JS */
/* Или вручную в контенте: */
<p>В&nbsp;2024&nbsp;г. мы работаем лучше</p>
```

## ЧАСТЬ 5: ПЕРЕНОСЫ

### 5.1 CSS hyphens

```css
:lang(ru) {
  hyphens: auto;
  word-break: break-word; /* Fallback */
  overflow-wrap: break-word;
}
```

### 5.2 Правила переносов в русском

- Перенос по слогам: ко-рова, мо-ло-ко
- Нельзя оставлять одну букву: о-са (неправильно), оса (правильно — не переносить)
- Нельзя отрывать ь, ъ, й от предыдущей буквы: поль-за, объ-ём
- Нельзя отрывать предлог от слова: в доме (не переносить)

### 5.3 Мягкий перенос

Для ручного контроля: `&shy;` (U+00AD)

```html
<p>Электро&shy;фицирован&shy;ный</p>
```

## ЧАСТЬ 6: РАЗМЕРЫ ШРИФТОВ

### 6.1 Минимальные размеры для русского текста

Кириллические буквы визуально мельче латинских при том же размере. Поэтому минимальные размеры нужно увеличить:

| Элемент | Латиница | Кириллица |
|---------|----------|-----------|
| Body text | 16px | 16-17px |
| Small text | 12px | 13-14px |
| Caption | 11px | 12px |
| Button text | 14px | 14-15px |

### 6.2 Вес шрифта

Кириллический текст при light weight (300) хуже читается чем латиница. Рекомендации:
- Body: 400 (regular) — минимум
- Заголовки: 500-700 (medium-bold)
- Кнопки: 500-600 (medium-semi-bold)
- Избегать 100-300 для длинного русского текста

## ЧАСТЬ 7: ФОРМАТЫ ДАТ И ЧИСЕЛ

### 7.1 Даты

- Формат: DD.MM.YYYY (31.12.2026)
- Месяц прописью: 1 января 2026 г.
- Сокращённый: 1 янв 2026

```typescript
new Intl.DateTimeFormat('ru-RU', {
  year: 'numeric', month: 'long', day: 'numeric'
}).format(date)
// "1 января 2026 г."
```

### 7.2 Числа

- Разделитель тысяч: пробел (1 234 567)
- Десятичный разделитель: запятая (1,5)
- Валюта: символ после числа (1 000 ₽)

```typescript
new Intl.NumberFormat('ru-RU').format(1234567.89)
// "1 234 567,89"

new Intl.NumberFormat('ru-RU', { style: 'currency', currency: 'RUB' }).format(4999)
// "4 999 ₽"
```

### 7.3 Телефоны

- Формат: +7 (XXX) XXX-XX-XX
- Или: 8 (XXX) XXX-XX-XX (внутренний формат)
- Маска ввода обязательна

```html
<input type="tel" placeholder="+7 (___) ___-__-__"
  pattern="\+7\s?\(\d{3}\)\s?\d{3}-\d{2}-\d{2}">
```

## ЧАСТЬ 8: FONT PAIRING ДЛЯ КИРИЛЛИЦЫ

### 8.1 Проверенные пары для русского языка

| Heading | Body | Стиль | Сегмент |
|---------|------|-------|--------|
| Inter 600-700 | Inter 400 | Современный, нейтральный | Универсальный |
| Montserrat 700 | Inter 400 | Контрастный, выразительный | EdTech, SaaS |
| PT Serif 700 | PT Sans 400 | Классический, тёплый | Медиа, культура |
| IBM Plex Sans 600 | IBM Plex Sans 400 | Технологичный | B2B, Fintech |
| Geist 700 | Geist 400 | Минималистичный | Стартапы, IT |
| Noto Serif 700 | Noto Sans 400 | Универсальный, читаемый | Порталы, гос.сайты |

### 8.2 Правила pairing для кириллицы

- НЕ смешивать шрифты разных стилей (скруглённый + угловатый)
- Контраст весов, не стилей: один шрифт с разными weight
- Проверить кириллические глифы ОБОИХ шрифтов — не все поддерживают
- Тестировать: «Ш», «Щ», «Ъ», «Ё» — проблемные символы

## ЧАСТЬ 9: КАПИТАЛИЗАЦИЯ — В РУССКОМ НЕТ TITLE CASE

### 9.1 Критическое отличие

В русском языке **НЕТ Title Case**. Каждое слово с заглавной буквы — это англоязычная конвенция, которая выглядит неестественно на русском.

**ПРАВИЛА капитализации для русского:**
- Заголовки: только первая буква заглавная («Оформление заказа»)
- Названия кнопок: только первая буква заглавная («Рассчитать стоимость»)
- Меню: только первая буква заглавная («Каталог товаров»)
- Исключение: собственные имена, бренды («Яндекс», «СберБанк»)
- Исключение: аббревиатуры (ООО, ИП, ГОСТ, ИНН)

```css
/* ПРАВИЛЬНО для русского: */
.button { text-transform: none; } /* Не uppercase! */

/* НЕПРАВИЛЬНО: */
.button { text-transform: uppercase; } /* Выглядит как КРИК на русском */

/* ЕСЛИ нужен uppercase — только для коротких меток: */
.badge { text-transform: uppercase; font-size: 11px; letter-spacing: 0.05em; }
/* «НОВИНКА», «СКИДКА» — допустимо для бейджей */
```

### 9.2 Uppercase в русском — когда допустимо

- Бейджи: «НОВИНКА», «ХИТ», «СКИДКА» — короткие, 1 слово
- Навигационные метки: «МЕНЮ» — но лучше строчные
- Аббревиатуры: «НДС», «ПВЗ» — это не uppercase, это аббревиатуры

### 9.3 Чего НЕ делать

- НЕ писать заголовки в Title Case: «Оформление Заказа» — неправильно
- НЕ делать все кнопки uppercase: «ОФОРМИТЬ ЗАКАЗ» — слишком агрессивно
- НЕ использовать uppercase для длинного текста — нечитаемо

## ЧАСТЬ 10: АББРЕВИАТУРЫ И ТИПОГРАФИКА

### 10.1 Российские аббревиатуры в UI

| Аббревиатура | Расшифровка | Контекст |
|-------------|-------------|----------|
| ООО | Общество с ограниченной ответственностью | Footer, реквизиты |
| ИП | Индивидуальный предприниматель | Footer, B2B формы |
| ИНН | Идентификационный номер налогоплательщика | Формы, footer |
| ОГРН | Основной гос. регистрационный номер | Footer |
| КПП | Код причины постановки на учёт | B2B формы |
| НДС | Налог на добавленную стоимость | Цены, чеки |
| ПВЗ | Пункт выдачи заказов | Доставка |
| СДЭК | Компания доставки | Доставка |
| ГОСТ | Гос. стандарт | Сертификаты |

### 10.2 Типографика аббревиатур

```css
/* Аббревиатуры: малые заглавные или обычные заглавные */
.abbr {
  font-variant-caps: all-small-caps;
  letter-spacing: 0.05em;
  /* Или просто: */
  text-transform: uppercase;
  font-size: 0.85em;
  letter-spacing: 0.05em;
}
```

**Правило:** Аббревиатуры в русском тексте НЕ разделяются точками: ИНН (не И.Н.Н.), ООО (не О.О.О.). Исключение: «т.д.», «т.е.» — сокращения, не аббревиатуры.

## ЧАСТЬ 11: VARIABLE FONTS И RESPONSIVE TYPE

### 11.1 Variable fonts с кириллицей

Variable fonts (переменные шрифты) поддерживают бесшовную анимацию веса и ширины. Для кириллицы доступны:

- **Inter Variable:** Полная кириллица, все оси (weight 100-900)
- **Noto Sans Variable:** Полная кириллица + казахские символы
- **Roboto Flex:** Кириллица, множество осей

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/InterVariable.woff2') format('woff2-variations');
  font-weight: 100 900;
  font-stretch: 100%;
  font-display: swap;
  unicode-range: U+0400-045F, U+0490-0491;
}

/* Использование: */
.heading { font-weight: 650; } /* Тонкая настройка веса */
.heading-condensed { font-stretch: 90%; } /* Уже для плотных заголовков */
```

### 11.2 Responsive type scale для русского

```css
:root {
  /* Fluid type scale — Russian */
  --font-size-sm: clamp(13px, 0.8rem + 0.25vw, 14px);
  --font-size-base: clamp(15px, 0.9rem + 0.3vw, 17px);
  --font-size-lg: clamp(18px, 1.1rem + 0.4vw, 22px);
  --font-size-xl: clamp(22px, 1.3rem + 0.6vw, 30px);
  --font-size-2xl: clamp(28px, 1.6rem + 1vw, 48px);
  --font-size-3xl: clamp(36px, 2rem + 1.5vw, 72px);
}

/* Кириллица крупнее на 1px: */
:lang(ru) {
  font-size: calc(var(--font-size-base) * 1.03);
}
```

### 11.3 Copy-paste проблемы с кириллицей

При копировании русского текста из Word/PDF:
- Кавычки-ёлочки могут замениться на машинные (" ")
- Тире может стать дефисом (-)
- Неразрывные пробелы теряются
- Буква ё может быть заменена на е

**Решение:** Функция «типографирования» на input:
```javascript
function typographText(text) {
  return text
    .replace(/"/g, '«') // Машинные кавычки -> ёлочки
    .replace(/"/g, '»')
    .replace(/ - /g, ' — ') // Дефис -> тире с пробелами
    .replace(/(\d) (руб|тыс|млн|млрд)/g, '$1\u00A0$2') // Неразрывный пробел
}
```

## Step-by-step execution protocol

1. **Select fonts:** Выбрать шрифты с полной кириллической поддержкой
2. **Setup font loading:** Предзагрузка critical fonts, font-display: swap
3. **Configure line-height:** Установить увеличенный line-height для кириллицы
4. **Test text expansion:** Проверить все кнопки, навигацию, карточки при +20% текста
5. **Setup typographic symbols:** Кавычки-ёлочки, тире, ё, неразрывные пробелы
6. **Configure hyphens:** Включить hyphens: auto для русского
7. **Check font sizes:** Убедиться что минимальные размеры достаточны для кириллицы
8. **Setup Intl formatting:** Даты, числа, валюты через Intl API с locale ru-RU
9. **Phone input mask:** Настроить маску для российских номеров
10. **Visual QA:** Проверить рендеринг на разных ОС и браузерах

## Scope boundaries

### DOES
- Рекомендовать шрифты с кириллицей
- Настраивать line-height и размеры для русского текста
- Настраивать типографские символы (кавычки, тире, ё)
- Рекомендовать text expansion решения
- Настраивать форматы дат, чисел, телефонов для РФ

### DOES NOT
- Создавать кастомные шрифты
- Настраивать i18n framework (используй internationalization-localization skill)
- Переводить контент
- Настраивать RTL (используй rtl-design skill)

## Error handling

| Scenario | Response |
|----------|----------|
| Шрифт без кириллицы | Заменить на Inter, Noto Sans, PT Sans — гарантированная кириллица |
| Кнопки переполнены русским текстом | Увеличить max-width, добавить text-overflow: ellipsis |
| Текст плохо читается | Увеличить font-size на 1px, font-weight до 400, line-height до 1.6 |
| Кавычки-лапки вместо ёлочек | Настроить CSS quotes для :lang(ru) |
| Нет буквы ё в UI | Добавить ё во все UI-тексты и кнопки |
