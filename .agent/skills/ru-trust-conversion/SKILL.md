# Доверие и конверсия на рынке РФ/СНГ

## When to activate

- Проектирование конверсионных элементов для российского рынка
- Настройка доверительных элементов (реквизиты, отзывы, гарантии)
- 152-ФЗ compliance (согласия, cookie, политика конфиденциальности)
- Маркировка рекламы
- Пользователь упоминает: доверие, конверсия, 152-ФЗ, ИНН, оферта, маркировка, CTA

## ЧАСТЬ 1: ПАРАДОКС ДОВЕРИЯ НА РЫНКЕ РФ

### «Недоверчивый по умолчанию»

Если американский пользователь доверяет по умолчанию (trust by default), то российский — недоверчив по умолчанию и требует доказательств. Это результат: высокой доли мошенничества в интернете (по данным ФНС, 30% сайтов в определённых категориях — мошеннические), слабой правовой защиты потребителя в онлайне, культурной привычки «проверять».

**Следствие:** каждый элемент доверия = +конверсия. Убрать элемент = потерять покупателей.

## ЧАСТЬ 2: ОБЯЗАТЕЛЬНЫЕ ДОВЕРИТЕЛЬНЫЕ ЭЛЕМЕНТЫ

### 2.1 Footer — юридический минимум

```html
<footer>
  <!-- ОБЯЗАТЕЛЬНО для коммерческого сайта в РФ: -->
  <div class="company-info">
    <p>ООО "Название Компании"</p>
    <p>ИНН: 7700000000 | ОГРН: 1027700000000</p>
    <p>Юридический адрес: 123456, г. Москва, ул. Примерная, д. 1, оф. 100</p>
    <p>Тел.: +7 (495) 123-45-67</p>
    <p>Email: info@company.ru</p>
  </div>
  <div class="legal-links">
    <a href="/privacy">Политика конфиденциальности</a>
    <a href="/terms">Пользовательское соглашение</a>
    <a href="/offer">Оферта</a>
  </div>
</footer>
```

**Почему критично:** отсутствие реквизитов = «сомнительный сайт» для российского пользователя. Это первый признак, по которому отличают «настоящий» сайт от мошеннического.

### 2.2 Телефон на видном месте

В отличие от Запада, где phone number опционален, в РФ он обязателен:
- Header: телефон с кодом города или 8-800
- Кликабельный (tel: ссылка для мобильных)
- «Заказать звонок» рядом с номером
- Время работы рядом

### 2.3 Физический адрес

- На странице контактов: карта (Яндекс.Карты или 2GIS)
- В footer: краткий адрес
- Для e-commerce: адрес пункта выдачи / самовывоза

### 2.4 Логотипы клиентов и партнёров

- Логотипы известных компаний-клиентов = сильнейший социальное доказательство
- Для B2B: 8-12 логотипов в секции «Нам доверяют»
- Для B2C: логотипы партнёров, банков, платёжных систем

### 2.5 Отзывы

- Текстовые отзывы с именем, датой, фото
- Видео-отзывы (набирают популярность)
- Интеграция с Яндекс.Картами (отзывы прямо на сайте)
- Звёздный рейтинг + количество отзывов
- Отзывы из соцсетей (VK, Telegram)

## ЧАСТЬ 3: 152-ФЗ COMPLIANCE

### 3.1 Согласие на обработку персональных данных

**Обязательно при каждой форме:**

```html
<div class="consent">
  <input type="checkbox" id="consent" required>
  <label for="consent">
    Я согласен(а) на обработку персональных данных
    в соответствии с <a href="/privacy">Политикой конфиденциальности</a>
  </label>
</div>
```

**Правила:**
- Чекбокс НЕ предустановлен (не pre-checked)
- Ссылка на политику — активная (кликабельная)
- Текст должен быть читаемым (не мелкий серый)
- Расположен рядом с кнопкой отправки

### 3.2 Политика конфиденциальности

Обязательные разделы:
- Какие данные собираются
- Для чего используются
- Кто обрабатывает (оператор)
- Сроки хранения
- Права субъекта данных
- Контакты ответственного

### 3.3 Cookie consent

Требуется, но менее строгое чем GDPR:
- Достаточно одного баннера: «Мы используем cookies для улучшения работы сайта»
- Кнопка «Принять» (не нужны granular options)
- Можно использовать «Продолжая использовать сайт, вы соглашаетесь...»
- Вариант с настройкой: «Настроить cookies» (необязательно, но плюс к доверию)

```html
<div class="cookie-banner">
  <p>Мы используем cookies для улучшения работы сайта.
    <a href="/privacy">Подробнее</a>
  </p>
  <button>Принять</button>
</div>
```

## ЧАСТЬ 4: МАРКИРОВКА РЕКЛАМЫ

### 4.1 Обязательные элементы для рекламы

С 2022 года вся реклама в интернете должна быть маркирована:
- Слово «Реклама» или «Рекл.» на видном месте
- ИНН рекламодателя
- Токен ОРД (оператор рекламных данных) в URL

### 4.2 Где маркировка обязательна

- Таргетированная реклама (VK, Яндекс)
- Реклама у блогеров (инфлюенс-маркетинг)
- Email-рассылки рекламного характера
- PR-статьи с оплатой
- Нативная реклама

### 4.3 Design решения

```html
<!-- Для баннерной рекламы -->
<div class="ad-label">
  <span class="ad-marker">Реклама</span>
  <span class="ad-advertiser">ИНН 7700000000</span>
</div>
```

Стиль: мелкий, но читаемый текст. Не прятать. Цвет: серый, но контрастный к фону.

## ЧАСТЬ 5: CTA-ПАТТЕРНЫ ДЛЯ РФ

### 5.1 Текст кнопок — прямолинейность

| Западный CTA | Российский CTA | Почему |
|-------------|----------------|--------|
| Get started | Начать работу | Конкретика |
| Learn more | Узнать подробнее | Прямолинейность |
| Sign up | Зарегистрироваться | Ясность |
| Buy now | Купить / Заказать | Действие |
| Get a quote | Рассчитать стоимость | Конкретика |
| Contact us | Получить консультацию | Выгода |
| Subscribe | Подписаться | Ясность |
| Try free | Попробовать бесплатно | Конкретика |

### 5.2 Цены с конкретикой

Российский пользователь хочет знать цену ДО клика:
- «от 990 руб/мес» — стандарт
- «Бесплатно первые 14 дней» — для SaaS
- «Рассрочка 0% от 990 руб/мес» — для дорогих продуктов
- Никогда: «Цена по запросу» (для B2C — смерть конверсии)

### 5.3 Несколько CTA

Российский landing page обычно имеет 2-4 CTA:
1. Основная: «Заказать» / «Начать» / «Рассчитать»
2. Вторичная: «Получить консультацию» / «Скачать прайс»
3. Третичная: «Смотреть демо» / «Прочитать кейс»

### 5.4 Pop-up и лид-магниты

Более агрессивные, чем на Западе:
- Скидка за подписку: «Скидка 10% на первый заказ» — стандарт
- Чек-лист / гайд за email
- Бесплатная консультация
- Таймер обратного отсчёта (использовать осторожно — может раздражать)

### 5.5 Онлайн-консультант

- JivoSite, Carrot Quest, Webim — стандартные виджеты
- Приветственное сообщение: «Здравствуйте! Чем могу помочь?»
- Время ответа: «Ответим за 30 секунд»
- Критично для B2B и e-commerce

## ЧАСТЬ 6: ГАРАНТИИ И ВОЗВРАТЫ

### 6.1 Обязательные элементы

- Гарантия возврата: «Возврат в течение 14 дней»
- Условия возврата: чёткие, без мелкого шрифта
- Служба поддержки: телефон, email, чат
- FAQ: ответы на частые вопросы

## ЧАСТЬ 7: СОЦИАЛЬНЫЕ ДОКАЗАТЕЛЬСТВА

### 7.1 Цифры доверия

Обязательные для российского landing page:
- Количество клиентов: «Более 50 000 клиентов»
- Количество заказов: «Более 1 000 000 заказов»
- Рейтинг: «4.8 из 5 на Яндекс.Картах»
- Года работы: «Работаем с 2010 года»
- Скорость: «Доставка за 2 часа»

### 7.2 Кейсы

Для B2B — кейс > отзыв:
- Проблема клиента
- Решение
- Результат в цифрах: «Увеличили продажи на 340%»
- Логотип + название компании

## ЧАСТЬ 8: PRICE ANCHORING — «ЗАЧЁРКНУТАЯ ЦЕНА»

### 8.1 Почему зачёркнутая цена работает в РФ

Price anchoring (was/now pricing) — один из самых мощных конверсионных инструментов на российском рынке. Это работает сильнее чем на Западе из-за: высокой чувствительности к цене, культуры скидок и распродаж (Black Friday, 11.11), ощущения «выгоды» как основного мотиватора покупки.

**Формат отображения:**
```html
<div class="price-block">
  <span class="price-old">5 990 ₽</span>
  <span class="price-current">3 990 ₽</span>
  <span class="price-discount">-33%</span>
  <span class="price-installment">от 333 ₽/мес</span>
</div>
```

### 8.2 Правила price anchoring для РФ

- Старая цена ВСЕГДА зачёркнута, не просто серая
- Процент скидки — крупно и контрастно (красный/оранжевый)
- Цена в рассрочку — рядом с основной ценой
- Для B2C: «Вы экономите 2 000 ₽» — конкретика
- Таймер скидки: «Скидка действует ещё 2 дня» — срочность

## ЧАСТЬ 10: ПРОМОКОДЫ И КУПОНЫ

### 10.1 Промокод-культура в РФ

Промокоды в РФ — мощный инструмент. Российский потребитель активно ищет промокоды перед покупкой. Отсутствие поля промокода может увеличить брошенные корзины.

**Проблема:** Поле промокода может заставить пользователя уйти искать промокод и не вернуться.

**Решение:** Ссылка вместо поля:
```html
<!-- ПЛОХО: Открытое поле -->
<input type="text" placeholder="Введите промокод">
<!-- Пользователь уйдёт искать промокод -->

<!-- ХОРОШО: Скрытая ссылка -->
<a href="#" class="promo-toggle">У меня есть промокод</a>
<!-- После клика раскрывается поле -->
```

### 10.2 Автоматические промокоды

Лучший подход — применять промокоды автоматически:
- При переходе из email-рассылки — промокод в URL
- При переходе из рекламы — промокод в UTM
- Скидка первого заказа — автоматически при регистрации
- «SKIDKA10» показан в корзине как уже применённый

## ЧАСТЬ 11: БРОШЕННАЯ КОРЗИНА

### 11.1 Восстановление корзины в РФ

Доля брошенных корзин в РФ: 70-80% (как и в мире). Но каналы восстановления отличаются:

| Канал | РФ приоритет | Западный приоритет |
|-------|-------------|-------------------|
| Email | 3-й | 1-й |
| Push-уведомление | 2-й | 2-й |
| Telegram-бот | 1-й | Нет |
| SMS | 4-й | 3-й |
| ВК-сообщение | 5-й | Нет |

**Telegram-бот — главный канал восстановления в РФ.**

### 11.2 UX паттерн восстановления

1. Через 1 час: Push или Telegram — «Вы забыли товары в корзине"
2. Через 24 часа: Email — «Ваши товары ждут вас + скидка 5%"
3. Через 72 часа: Telegram/SMS — «Последний шанс! Скидка 10% на корзину"

### 11.3 Cross-sell в брошенной корзине

В письме/сообщении о брошенной корзине добавить:
- «С этим товаром покупают...»
- «Добавьте всего X руб для бесплатной доставки"
- «Купите в рассрочку от X руб/мес"

## Step-by-step execution protocol

1. **Trust audit:** Проверить наличие всех обязательных доверительных элементов
2. **Legal compliance:** Добавить 152-ФЗ согласия, cookie banner, реквизиты
3. **CTA optimization:** Заменить абстрактные CTA на конкретные для РФ
4. **Price display:** Показать цены «от», рассрочки, гарантии
5. **Social proof:** Добавить цифры, отзывы, логотипы клиентов
6. **Online consultant:** Настроить чат-виджет
7. **Guarantee section:** Добавить гарантии и условия возврата
8. **Ad labeling:** Пометить всю рекламу по правилам
9. **Conversion tracking:** Настроить цели в Яндекс.Метрике
10. **A/B testing:** Тестировать конкретные варианты CTA и доверительных элементов

## Scope boundaries

### DOES
- Проектировать доверительные элементы для РФ
- Настраивать 152-ФЗ compliance
- Рекомендовать CTA-паттерны для российского рынка
- Настраивать маркировку рекламы
- Рекомендовать лид-магниты и поп-апы

### DOES NOT
- Юридическая консультация (только awareness и чеклисты)
- Настраивать CRM и чат-виджеты технически (только рекомендации)
- Создавать контент для лид-магнитов
- Заменять A/B тестирование (только рекомендации по гипотезам)

## Error handling

| Scenario | Response |
|----------|----------|
| Нет реквизитов на сайте | Добавить IMMEDIATELY: ИНН, ОГРН, адрес, телефон в footer |
| Чекбокс согласия pre-checked | Снять pre-check — нарушение 152-ФЗ |
| CTA абстрактный «Get started» | Заменить на конкретное действие + выгоду |
| Нет цены на landing page | Добавить «от X руб/мес» или «Бесплатно первые N дней» |
| Нет онлайн-консультанта | Добавить чат-виджет, хотя бы с асинхронным режимом |
