# Компактный шаблон финального плана (для средних задач)

Используется модератором для средних задач (4-5 ролей). Сохраняется в файл `/home/z/my-project/download/plan-[task-name].md`. В чат идёт выжимка по формату `developer-output.md`.

Компактный шаблон включает только ключевые разделы. Полный шаблон (для высоких сложностей) — `plan-template.md` с 16 разделами.
