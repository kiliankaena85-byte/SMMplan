# 📑 Манифест Проекта «AI Legal War Room» (v2.1)

## 1. Архитектурная концепция
Мы создаем многоагентную систему принятия стратегических решений в праве. Система имитирует работу консилиума из узкоспециализированных юристов, где передача данных между узлами жестко регламентирована кодом и структурированными форматами данных (JSON/Markdown). Это минимизирует хаотичное раздувание контекста (Context Bloating) и снижает риск галлюцинаций.

## 2. Ключевые инженерные принципы
1. **Гибридный метод.** Поиск решений строится на синергии догмы права (законы) и прецедентной практики (судебные решения).
2. **Временная консистентность (Temporal Consistency).** Применимость норм проверяется строго на дату события. Фильтрация законов по времени действия происходит на стороне базы данных (RAG), а не «в голове» модели.
3. **Оценка рисков через «Цену ошибки».** Любая стратегия оценивается с точки зрения финансового и репутационного ущерба, вероятности его наступления и возможностей предотвращения.
4. **Управление состоянием (State Machine).** Переходы между агентами контролируются программным оркестратором. В случае критического уровня риска система автоматически запускает цикл самопроверки (Self-Correction Loop).

## 🗄 Схемы метаданных для Векторных Баз Данных

### 1. Коллекция `collection_law` (Законодательство)
```json
{
  "id": "uuid",
  "vector": [0.012, -0.085, "..."],
  "payload": {
    "domain": "tax_law_ru",
    "act_name": "Налоговый кодекс РФ",
    "article": "Статья 105.1",
    "text": "Полный текст статьи или конкретной части...",
    "effective_from": 1672531200, // Unix timestamp вступления в силу
    "effective_to": 1704067200,   // Unix timestamp окончания действия (или null)
    "source_url": "https://consultant.ru/..."
  }
}
```

### 2. Коллекция `collection_cases` (Судебная практика)
```json
{
  "id": "uuid",
  "vector": [0.034, 0.112, "..."],
  "payload": {
    "domain": "tax_law_ru",
    "case_number": "А40-12345/2024",
    "court_name": "АС Московского округа",
    "date": 1715731200,
    "ruling": "SUCCESS", // Исход: SUCCESS (в пользу клиента) или FAILED (в пользу оппонента)
    "key_arguments": "Ключевые факторы успеха или ошибок...",
    "text_summary": "Сжатое изложение дела и выводов суда...",
    "source_url": "https://kad.arbitr.ru/..."
  }
}
```
