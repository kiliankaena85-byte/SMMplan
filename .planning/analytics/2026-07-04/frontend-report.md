# 🔎 UI/QA Report — Smmplan (2026-07-04)

## 1. Проверка дизайн-системы и верстки
* **Tailwind CSS v4:** Стилизация выполнена по CSS-first конфигурации в `globals.css` с использованием `@theme` директив. Локальные inline цвета (например, `text-white`, `bg-black`) отсутствуют в ключевых компонентах, используются семантические токены (`text-foreground`, `bg-background`).
* **Компоненты HeroUI v3:** Во всех новых формах используется правильный dot-notation API (например, `<Table.Header>`).
* **Select trigger labels:** В селекторах реализована children-функция `{(value) => resolveLabel(value)}` на `<SelectValue>` для предотвращения показа сырых CUID-идентификаторов.

## 2. Кросс-браузерная и кросс-платформенная стабильность
* В ходе E2E тестирования исправлены проблемы с HTML5-валидацией Chromium на числовых полях ввода (точность наценки ограничена до 4 знаков, `step` изменен на `"any"`).
* Сетка админ-панели и форм создания заказов корректно отображается при разрешении от 320px до 4K.

## 3. Рекомендации
* **Контроль размеров файлов:** Убедиться, что размер страниц не превышает 150-200 строк. Крупные компоненты (такие как `CatalogTable`) декомпозировать на изолированные субкомпоненты.
* **Микро-анимации:** Добавить плавные переходы (`transition-all duration-200`) на интерактивные кнопки панели для улучшения тактильного отклика интерфейса.
